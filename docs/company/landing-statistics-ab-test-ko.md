# 홈 랜딩 통계 표시 A/B

구현 기준: 2026-10-21. 이 문서는 코드 계약이며 운영 배포 완료를 의미하지 않는다.

- `/`, `/ko`, `/en`에서 인재 로고 영역 바로 아래 통계 3개를 표시하는 효과를 비교한다.
- A: 기존 화면. B: `LandingStats` 표시. `/company`는 실험 대상이 아니며 항상 같은 공통 컴포넌트를 표시한다.
- `career_landing_stats_v1`: SSR에서 브라우저 쿠키로 50:50 배정한다. 1년간 유지하며 언어 변경·재방문에도 같은 그룹이다. 응답은 `private, no-store`다.
- 기존 hero copy·signup flow 실험의 ID와 로그를 바꾸지 않는다.

## 집계

Ops → A/B 테스트 → **홈 랜딩 통계 표시**.

로그아웃 상태에서 홈이 준비되면 두 그룹 모두 `landing_logs`에 `landing_stats_exposure`를 기록한다. 스크롤 도달·통계 로딩 성공을 표본 조건으로 쓰지 않는다. API가 실패한 B 방문자도 그대로 포함한다. 개발 환경에서는 새 실험 노출 로그를 보내지 않는다.

선택 기간의 첫 노출을 기준으로 브라우저(`local_id`)당 한 번 센다. 같은 ID에 서로 다른 그룹 기록이 있다면 첫 그룹에 귀속한다.

| 지표 | 기준 |
| --- | --- |
| 주 지표: 신규 가입 완료율 · 24시간 | 첫 방문 후 24시간 내 `career_signup_completed` 서버 기록이 있는 브라우저 / 24시간 관찰 완료 브라우저 |
| 24시간 관찰 중 | 아직 첫 방문 후 24시간이 지나지 않은 브라우저. 주 지표와 신뢰구간에서는 제외 |
| 가입 완료 브라우저 | 관찰 중인 표본을 포함하여 24시간 창 안에서 확인된 가입 수 |
| 시작 클릭률 | 24시간 관찰 완료 표본의 `click_start` 계열 기록 |
| 이메일 제출률 | 같은 표본의 `email_capture_sent` 또는 `email_capture_already_sent` 기록. 제출 시도·오류는 제외 |
| 로그인 전환율 | 같은 표본의 `login_email` 기록. 기존 계정 로그인도 포함하므로 신규 가입과 별도 |

인증 bootstrap은 기존 신규 가입 로그에 `landingLocalId`, `landingPath`, `landingSource` 메타데이터를 추가한다. 실제 가입 판정은 기존 서버의 신규 `talent_users` 생성 경로를 그대로 따른다. CTA 클릭이나 로그인만으로 가입 완료로 간주하지 않는다. 가입·로그인 방식별 기존 `abtest_type`에 관계없이 같은 방문 ID로 연결한다.

Ops는 선택 기간의 실험 노출 ID를 먼저 읽고 해당 ID의 랜딩 이벤트·가입 로그만 페이지 단위로 조회한다. 새 테이블·migration은 필요 없다. 기존 이메일 제외 필터와 내부 이메일 제외를 적용한다. Ops 캐시는 30초다.

## 해석과 한계

- 최초 24시간에는 표본 수와 가입 완료 수가 먼저 보이고, 비교 전환율은 아직 계산되지 않는다.
- 표본은 계정이 아닌 브라우저다. 저장소 삭제·다른 기기·브라우저별로 방문 ID가 달라질 수 있다.
- 기간 필터는 그 기간 안 첫 방문을 기준으로 한다. 서로 겹치는 기간의 표본은 독립적이지 않다.
- 신규 가입은 인증을 마치고 웹 프로필이 생성되는 시점이다. 이메일 제출·메일 대화만으로는 가입 완료가 아니다.
- 로그인하지 않은 내부 방문자는 이메일을 알 수 없어 제외하지 못한다.
- 기존 Ops의 95% 구간 비교를 사용한다. 반복 조회하면서 순간적인 우세만 보고 승자를 확정하지 않는다.

## 로컬 확인

- `/ko?landing_stats=A`: 통계 없음.
- `/ko?landing_stats=B`: 통계 표시. `/en`도 동일.
- query override는 개발 환경에서만 적용하며 선택한 값은 쿠키에 남는다. 운영에서는 무시한다.
- 검증: `node --import tsx --test src/lib/landingStatsExperiment.test.ts src/lib/ops/landingStatsExperiment.test.ts`.
