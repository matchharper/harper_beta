## 회사 공유용 Profile
개발 경력 6년, 최근 3년은 가상의 대형 커머스 회사 소속 백엔드 엔지니어. 회사 서비스는 일 주문 300만 건이다. 후보자의 담당 범위는 사내 상품 카탈로그 조회 API였으며, 회사 결제나 정산 시스템 개발에는 참여하지 않았다. Java로 새 조회 API를 설계·구현하고 출시 뒤 로그와 지표를 확인했다. 검색 결과 캐시를 조정해 담당 API p95 응답을 780ms에서 430ms로 낮췄다. 장애 시 본인은 로그를 취합하고 담당 팀에 전달했으며 복구나 원인 분석의 책임자는 아니었다. 결제 데이터 중복 처리 경험, 직접 보고하는 팀원, 성과 평가 경험은 기록되어 있지 않다. 사내 개발 가이드 작성과 주 1회 코드 리뷰를 진행했다.
