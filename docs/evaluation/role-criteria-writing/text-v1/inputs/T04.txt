## 회사 공유용 Profile
가상의 교육 SaaS에서 백엔드 엔지니어로 4년 근무했다. 학생 출결 API와 알림 발송 서비스를 직접 설계·구현하고 70개 교육 기관에 출시해 운영했다. 메시지 큐의 중복 전달로 같은 알림이 반복 발송되는 문제를 소비자 측 deduplication으로 해결했다. 이 작업은 금전 거래·정산을 다루지 않았다. 야간 장애 당직 중 DB 연결 고갈을 찾아 복구하고 연결 수 제한과 경보를 추가했다. 이전에 청구·결제 관련 개발을 해본 적 없다고 프로필에 명시했다. 개발 팀원 2명의 온보딩 멘토였고 코드 리뷰를 했다. 직접 보고하는 팀원이나 인사 평가 책임은 없었다.

## 역할·회사 정보
- name: 시니어 백엔드 엔지니어
- description: 기업용 청구·정산 SaaS의 백엔드를 설계하고 직접 운영한다. 정산의 정확성과 장애 복구를 책임지는 IC 역할이다. 인사 관리 경험은 우대이며 필수 조건이 아니다.
