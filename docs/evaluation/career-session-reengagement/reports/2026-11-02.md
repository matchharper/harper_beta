# 재접속 입력 및 응답 확인 — 로컬, 미배포

공통 `runCareerChatTurn`에서 사용자 발화 없이 시작한 turn에 “새 실행 결과로 위임 작업을 계속하라”는 합성 user 메시지를 추가하던 코드를 삭제했다. 최근 대화는 원래 역할·순서로 유지하고 호출 목적은 기존 runtime context로 전달한다. recovery도 같은 실제 이력을 사용한다.

재접속 지침은 반갑게 맞이하는 인사와 함께 대화를 다시 여는 목적, 현재 사실과 액션/무응답 계약을 제공한다. 주제별 제안 목록과 연속 주제 금지 규칙을 제거했다. 고정 인사, 출력 단어 차단, 별도 재작성 모델을 추가하지 않았다.

## 실제 제공자 호출

Frozen `session-return-v1` 합성 4건, gold v1. 실제 chatTurn 입력 조립 → 제품 `runCareerChatAssistant` → OpenAI Responses. 현재 기본 `gpt-6.1-sol`, reasoning `high`, store=false. 호출부 temperature는 0.8이지만 제공자 요청에는 제품 adapter가 해당 필드를 생략한다. 제공자 요청에서 시스템 맥락과 원래 user/assistant 이력만 전달된 것을 구조 비교로 확인했다.

- 첫 run `20261102-session-return-v1`: 4건 생성. 잘못된 실행 결과 보고는 없어졌지만 인사 없이 본론으로 진입해 품질 미완료로 판정했다.
- 최종 run `20261102-session-return-v2`: 같은 입력·gold로 목적 문장을 명확히 한 뒤 4건 재실행. 전부 원문을 읽고 판정했다. 4건 모두 제공자 요청 1회이며 후처리 재작성 없음.

| 사례 | 확인 결과 |
| --- | --- |
| 미처리 항목 없음, assistant로 끝난 이력 | 인사 뒤 원하는 역할·팀 탐색을 제안. 지원을 서두르지 않는 맥락 유지. |
| 미처리 항목 없음, user로 끝난 이력 | 이전의 대화 종료 발화에 다시 답하지 않고 방문 인사 뒤 대화를 열었음. |
| 미팅 요청 있음, assistant로 끝난 이력 | 인사 뒤 기다리는 미팅과 팀 탐색 목적을 연결. 정확한 pending action 참조. |
| 미팅 요청 있음, user로 끝난 이력 | 인사 뒤 대화를 재개하고 미팅 요청을 안내. 정확한 pending action 참조. |

4건에서 새 실행 결과·조회 완료·공유 완료를 꾸며내는 응답은 없었다. 미처리 항목 없는 사례에 회사 요청을 만들어내지 않았다. 의미·자연스러움은 Codex 직접 검토이며 자동 키워드 점수가 아니다.

원문과 재현 정보: [최종 제공자 입력·응답](../runs/20261102-session-return-v2/outputs.json), [manifest](../runs/20261102-session-return-v2/manifest.json). raw 파일은 ignored 디렉터리·0600 권한이다. 실행 뒤 runner/harness에 formatting만 적용했으며 원 실행 source hash와 formatting 이후 hash를 구분했다.

## 구조 검증과 한계

- 재접속 목적·시각·pending 실행 계약, 실제 chatTurn의 양쪽 마지막 역할, 기존 provider checkpoint 재개와 실행 결과 보존 관련 검사 16개 통과. 비대상 13개는 이름 필터로 제외.
- 첫 넓은 검사에서 API key 없는 테스트 초기화 오류 1건은 테스트용 키로 재실행해 해결했다. 별도 `lifecyclePrompts.test.ts`의 feedback event 검사 1건은 이번에 바꾸지 않은 prompt 문구와 assertion이 불일치했다(실행 당시 361행). 범위 밖 prompt나 assertion을 수정하지 않았다.
- 실제 계정의 DB 조회, capability selector/동적 도구 실행, 화면 렌더링은 검증하지 않았다. 합성 read를 사용하고 model 경계 앞에서 실제 chatTurn 인자를 포착한 뒤 tools=[]로 제품 adapter를 호출했다. 전용 network guard가 OpenAI 외 목적지를 차단한다. 운영 쓰기·발송·배포는 하지 않았다.
- 기존 미커밋 변경을 유지했고, 이미 삭제된 기존 평가 registry 문서를 복원하지 않았다. 새 평가 계약은 이 task README에 등록했다.
