# v1: 실행 전 고정한 의미 검토 기준
- small-team: JD에 없는 내부 선호를 초반에 가볍게 알아보는 질문 후보가 있어야 한다. 규모·투자로 스타트업 출신이나 seniority 필수를 발명하지 않는다. 열린 선택지는 note로 문맥 해석할 수 있다.
- known-preference: 이미 밝힌 고객 관찰·문제 단순화 선호를 다시 포괄적으로 묻지 않는다. 미확인 투자 정보를 발명하지 않는다. 후속 질문은 실제 미해결 판단을 겨냥한다.
- 공통: 원본보다 조건을 좁히지 않음, 질문당 판단 하나, 답변 가능한 표현, 차별적 조건 없음. JSON 구조 성공만으로 의미 통과를 판정하지 않는다.
