# GLM 5.3 Flash active chat coaching quality review

## 판정

`z-ai/glm-5.3-flash`, reasoning `high`를 production active chat prompt와 v5 frozen fixture로 두 번 실행했다. 각 run은 서로 다른 세 대화, 총 22개 assistant 응답 기회로 구성된다.

두 run 모두 human quality gate는 **NO-GO**다.

| Run | 구조 결과 | Human quality | Critical failure |
| --- | --- | --- | --- |
| `20260922-glm-53-flash-high-v5-r1` | 3/3 구조 위반 없음 | 0/3 전체 통과 | 근거 없는 시장·직무 일반화, 결론 내부 모순, 제한된 증거에서 senior 수준 단정 |
| `20260922-glm-53-flash-high-v5-r2` | 2/3 구조 정상, PM 전환 1건 tool 오류 | 0/3 전체 통과 | 근거 없는 보상 범위, 출처 없는 비율·기간, 과도한 수준 단정, session 가설·일회성 계획 Memory 저장 |

구조 성공은 품질 점수로 계산하지 않았다. raw transcript와 provider output은 gitignored `runs/` 아래에만 보존한다.

## 좋아진 점

- 대부분의 턴에서 짧은 공감 뒤 질문만 하지 않고, 질문 전에 구분·가설·선택지·실험 설계를 제공했다.
- PM 전환과 일의 재미 저하 사례에서 사용자의 교정이 들어오면 초기 해석을 명시적으로 수정했다.
- 직접적인 판단 요청에는 질문을 더 이어가기보다 판단 틀을 제시한 턴이 있었다.
- 사용자가 종료를 요청하면 세 사례 모두 추가 코칭 질문 없이 activity를 끝냈다.

이 결과는 “답이 너무 짧아 질문만 한다”는 초기 실패가 완화됐다는 뜻이다. 다만 답변이 길고 그럴듯해진 뒤에도 근거와 논리가 틀리면 제품 품질은 통과할 수 없다.

## 공통 실패

### 근거 없는 일반론을 조언의 전제로 사용

PM 전환 성공 요인, PM 업무의 회의 비율, 검증에 필요한 주·개월과 확신 비율, 경력 전환자의 레벨, 회사 단계별 보상, 특정 도메인의 채용 선호처럼 외부 근거가 필요한 내용을 tool 결과 없이 단정했다. r2에서 사실·추론·외부 일반론을 분리하라는 prompt를 추가한 뒤에도 같은 유형이 반복됐다.

### 제한된 성과에서 시장 레벨을 과도하게 추론

비용 절감, MTTR, 설계 리뷰 경험은 강한 협상 재료지만 그 자체로 senior 또는 lead market level을 확정하지는 않는다. 모델은 반복해서 “이미 Senior 수준”, “사실상 리드 스코프”라고 결론 내렸고, 이 결론을 협상 전략의 전제로 사용했다.

### 구체적이지만 내부 논리가 맞지 않는 판단

r1의 일의 재미 저하 사례는 앞에서 “동료는 통과하고 본인만 잘리면 개인의 프레이밍·신뢰 문제”라고 설명했지만, 최종 기준에서는 같은 조건을 “구조 문제의 가장 강한 신호”라고 반대로 정리했다. 질문 전 분석이 길어진 것만으로는 일관성이 보장되지 않았다.

### Memory 경계 위반

r2의 일의 재미 저하 사례는 종료 시점에 잠정 진단, activity에서 정한 실험, 미래의 잔류·탐색 기준을 Memory에 저장했다. 이는 session control과 Harper의 종합 가설을 durable memory로 저장하지 않는 production 계약을 위반한다.

### 보상 사례의 치명적 사실성 실패

r2는 검색 결과를 얻지 못했다고 밝힌 직후 `+10%`, `+20%`, `+30%` 구간을 각각 흔한 선, 현실적 상한, 특정 조건이 필요한 영역으로 제시했다. 이후 사용자가 숫자를 지어내지 말라고 명시한 뒤에는 태도를 바꿨지만, 이미 첫 응답에서 핵심 요구를 위반했다. 또한 사용자가 보너스를 “보통 500”이라고 말했는데 이를 보장 금액으로 바꿔 해석했다.

| 사례 | r1 | r2 | 핵심 이유 |
| --- | --- | --- | --- |
| PM 전환 가설 교정 | Fail | Fail | 교정 반영과 실험 설계는 좋았지만 전환·직무·시장 일반론을 근거 없이 단정했고 r2에서는 출처 없는 비율과 기간까지 제시 |

| 보상과 근거 | Fail | Fail | 협상 재료 구조화는 유용했지만 senior 수준을 과도하게 확정했고 r2는 검색 근거 없이 보상 구간을 생성 |

## 결론

현재 GLM 5.3 Flash active chat은 **깊이와 대화 진전은 개선됐지만 사실성·추론 일관성·Memory 경계를 안정적으로 지키지 못한다.** 같은 frozen set의 두 번 실행에서 0/3이 반복됐으므로, prompt 문장을 더 추가하는 것만으로 production 품질이 확보됐다고 볼 수 없다.

다음 비교에서 의미 있는 선택지는 같은 v5를 더 강한 모델에 그대로 실행해 모델 한계와 prompt 한계를 분리하는 것이다. active coaching만 별도 모델을 쓰는 경우에도 일반 대화 모델과 lifecycle 구조는 그대로 유지할 수 있다.
