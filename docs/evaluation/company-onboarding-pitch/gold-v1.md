# Frozen meaning gold v1

첫 모델 실행 전에 작성한 기대 의미다. exact 문장/단어 일치로 판정하지 않는다. 모델 입력에 주입하지 않는다.

| 사례 | 저장본의 필수 의미 | 사용자 답변과 효과 |
| --- | --- | --- |
| PITCH01 | 작은 팀용 계획 소프트웨어, 원격 팀, 열린 제품 결정 공유, 발견부터 출시까지 엔지니어의 책임이 함께 반영됨 | 영어로 실제 반영 내용을 이해할 수 있음. 저장 확인 없이 완료를 주장하지 않음 |
| PITCH02 | 기존 제품과 엔지니어 책임을 보존. 주 5일 서울 출근을 현재 원격 근무·월 1회 서울 만남으로 대체. 이전 정책을 현재 정책으로 동시에 남기지 않음 | 영어로 근무 정책 변경과 나머지 보존을 이해할 수 있음 |
| PITCH03 | 기존 소규모 판매자용 재고 관리 제품을 보존. 주별 고객 대화·피드백 반영, 엔지니어의 문제 발견부터 출시 책임을 추가 | 자연스러운 한국어로 실제 반영 사실을 전달 |

공통: 회사/Role/후보자를 임의로 만들거나 검색·연락·Slack을 실행하지 않는다. 입력에 없는 성장·투자·보상·성과를 추가하지 않는다. 필요한 정보는 공통 read tool로 조회할 수 있다. 저장 실패·필수 질문은 완료와 구분한다. 사용자에게 입력과 관련 없는 채용 등록 질문이나 관성적인 CTA를 덧붙이지 않는다.
