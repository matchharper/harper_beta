# Frozen Pitch quality gold v2

2026-10-09 사용자 정정: 온보딩의 Pitch는 후보자에게 회사를 소개할 때 활용할 회사 자랑과 강점이다. v1은 사실 보존·정정·저장 위주였으므로 v2에서 목적 적합성을 별도 평가한다. v1의 파일·정답·실행은 변경하지 않는다.

PITCH01–03 입력은 v1과 동일하다. 해당 원문을 이미 본 뒤 만든 평가이므로 독립 검증이 아니다. PITCH04–06은 합성 확장 사례이며 v2 모델 실행 전에 작성했다. 자체 작성 gold이고 독립 팀원 검토는 아직 없다. 이 문서를 모델에 주입하지 않는다.

## 평가 단위와 공통 기준

실제 저장된 Pitch 전체와 완료 답변을 읽는다. Pitch는 Harper가 후보자에게 적절하게 회사를 소개할 수 있도록 정리한 회사의 가치 제안이다. 공개 광고 문구나 특정 양식, 제목·문장 수·표현을 요구하지 않는다.

- **회사 매력**: 어떤 회사인지와 합류를 매력적으로 만드는 구체적 근거를 파악할 수 있다. 업무 범위가 주어졌을 때 회사 문화·자율성·제품 영향력을 설명하는 맥락을 유지하며 지원자의 필수 경험이나 직무 수행 명령으로 바꾸지 않는다.
- **구체성과 사실성**: 제공한 제품, 성과, 환경, 문화, 지원 조건을 보존한다. 실제 근거 대신 상투적인 칭찬만 남기지 않는다. 입력에 없는 투자·성장·리더십·커리어 보장·미래 성과를 추가하지 않는다.
- **보존·정정·조건**: 기존의 유효한 회사 강점을 유지하고, 달라진 사실과 혜택의 적용 조건을 정확히 반영한다. 가능성·검토·계획을 확정 제공이나 현재 성과로 강화하지 않는다.
- **저장과 사용자 답변**: 실제 Pitch 저장과 완료 설명이 일치한다. 필요한 질문과 실패는 완료와 구분한다. 완료 후 관련 없는 빈 필드 입력이나 새 채용 업무를 요청하지 않는다. 미수행 작업의 관성적인 안내는 사용성 문제로 별도 기록한다.
- **효과·권한**: Pitch 외의 Role·후보자·연락·검색을 변경하지 않는다. fixture는 합성 로컬 회사이고 Role을 생성하지 않는다.

6/6 실제 저장, 회사 매력·필수 의미·조건 보존, 미승인 효과·허위 완료 0이 필수 gate다. 말투·장황함은 별도 사용성 판정이며 단어 매칭으로 품질을 판정하지 않는다. 속도는 별도 metric으로 남긴다.
