## 남긴 변경

- 일반 입력·날짜·숫자·기본 선택창·체크박스를 관측한 DOM 참조로 묶어서 처리하는 공통 도구를 추가했다. 대상 입력을 다시 찾는 별도 AI 호출을 줄인다. 특정 채용 사이트나 테스트 항목 이름을 코드에 넣지 않았다. 교체된 DOM 노드에는 이전 참조를 쓰지 않으며, 실패 또는 승인 대기 시 나머지 입력을 중단한다.
- 승인에 필요한 현재 입력값은 계속 읽되, 매 단계마다 긴 본문·설명·선택지까지 읽지 않는다. 여러 프레임은 병렬로 읽는다. 상세 화면 읽기는 기존 검사 도구·묶음 입력 결과·결과 보고에서 유지한다.
- 1 MiB 이하의 승인된 파일은 환경 생성 요청에 함께 넣어 별도 전송·설치 명령 왕복을 줄였다. 원본 파일명·내용 hash·단일 파일 5 MiB/총 10 MiB 경계는 검증한다. 큰 파일은 기존 분할 전송을 유지한다.
- 종료 시 브라우저 공급자 종료 요청과 실행 서버 종료 명령을 함께 시작한다. 실행 서버의 응답 지연 때문에 유료 브라우저 종료가 뒤로 밀리지 않게 했다. 이 정리 변경은 마지막 원격 실행에서 실제 종료를 확인했다.

기존 화면, 승인 계약, GPT-6-luna medium, 100단계, 30분 자원 만료는 유지한다. 알 수 없는 첨부 요청을 임의로 통과시키는 예외를 추가하지 않았다. 성공 실행의 승인이 9회인 이유는 도시 조회 1회, 첨부 관련 7회, 제출 1회다. 기존 승인 정책이 넓고 파일 전송 중 중복 시도가 남아 있어, 최종 승인 한 번만 필요한 완성된 경험이라고 주장하지 않는다. Browserbase와 Browser Use가 같은 수정 경로를 사용하지만 **이번 실제 브라우저 실행은 Browser Use만 검증**했다.
