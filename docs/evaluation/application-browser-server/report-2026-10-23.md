## 판정과 한계

- 원래 공고 기준으로 Xation·Peregrine 두 곳에서 필수 입력과 파일 첨부를 갖춘 제출 직전 상태를 직접 확인했다. 누아는 입력·첨부까지 확인했지만 이메일 확인은 미검증, SpaceX는 미완료, Science37은 공고 대체로 비교 불가다. 전체 성공률로 환산하지 않는다.
- 이 표본은 과거 **폼 조회·첨부 실패** 이력에서 골랐다. 과거의 전체 제품 제출 실패를 동일 조건으로 재현한 A/B 비교가 아니다. 사이트 내용·보안 상태와 에이전트가 모두 달라질 수 있다.
- 모든 최종 화면·필드 값과 업로드 응답을 검토했다. 모델의 성공 문장만으로 판정하지 않았다. Peregrine의 커스텀 선택창은 DOM 입력 value가 비어도 화면과 본문에서 실제 선택값을 확인했다. 누아의 모델 요약에 남은 전화번호 오류 추측은 최종 DOM·스크린샷에서는 보이지 않았다. SpaceX 기본 정보는 최종 증거상 채워졌지만 다른 필수 질문들이 남아 있었다.
- 실제 최종 제출, 제출 때 발생하는 CAPTCHA·서버 검증, 회사 측 장기 저장 여부는 검증하지 않았다. Science37 대체 공고의 거주지 선택은 한 옵션이 선택된 화면을 확인했지만 미선택 체크박스의 native validity 경고가 있어 서버 검증 완료로 해석하지 않았다.
- 합성 후보와 매우 작은 합성 파일만 사용했다. 실제 후보자의 사실·증빙·동의 정확성이나 대용량 첨부 성능을 평가하지 않았다.
