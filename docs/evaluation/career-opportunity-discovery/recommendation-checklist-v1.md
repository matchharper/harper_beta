# 추천 완성도 체크리스트 v1 (사용자 관점)

2026-11-17. 사용자가 "새 기회 찾아줘"처럼 추천을 요청했을 때, 받은 답변과 기회 카드만 보고 판단한다. 내부 로그는 근거를 확인할 때만 본다.

이 체크리스트는 결과를 보는 리뷰어용이다. 문항을 모델 지침이나 답변 대본으로 옮기지 않는다. 항목마다 몇 문장을 써야 하는지 정하지 않으며, 상황에 필요 없는 항목은 해당 없음으로 둔다.

## 통과 질문

> 이 답을 받은 사용자가 "링크드인·잡코리아·리멤버를 직접 뒤지는 것보다 Harper에게 맡긴 게 낫다"고 느끼는가?

아래 항목은 이 질문을 나눠 본 것이다. 각 항목은 0(없음), 1(부분), 2(충분)로 매긴다.

- 통과: A1·A2·A5·B1·B2·B3이 모두 1점 이상이고, 나머지에서 0점이 둘 이하이며, 리뷰어가 통과 질문에 "그렇다"고 답한다.
