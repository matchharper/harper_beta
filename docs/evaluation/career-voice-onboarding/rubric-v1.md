# Frozen rubric v1 — 2026-09-28

사용자가 승인한 목표: 첫 온보딩 통화에서 추천에 필요한 정보를 충분하고 정확하게 확보한 사용자 비율.

1. `readiness`: ready / not_ready / unknown. 기존 프로필 + 첫 통화에서 희망 역할·시점/의사·위치/근무방식·보상·주요 필수/기피조건과 우선순위가 추천할 만큼 확인됐는지 의미로 판단한다. 특정 질문 수, 문자열, 체크리스트 플래그, 턴 수, 통화 길이 또는 모델 종료 선언은 판정 기준이 아니다. 명시적 무관/미정도 유효한 답이다. 하나의 필드가 없다는 사실만으로 자동 실패시키지 않으며, 왜 추가 질문이 추천에 필수적인지 근거를 남긴다.
2. `fidelity`: pass / fail / unknown / not_applicable. 통화에서 확인된 중요한 정보가 당시 저장 결과에 충실하게 반영됐는지 본다. 중요한 누락, 원문에 없는 조건, 선호를 필수로 바꿈, 국적/근무자격 추정, 보상 숫자/범위 변경은 fail이다. 당시 저장 내용을 복원할 수 없으면 unknown이다. 충분성을 충족하지 못해 성공 후보가 아닌 사례는 not_applicable로 둘 수 있다.
3. `outcome`: ready는 readiness=ready이고 fidelity=pass일 때만 가능하다. 중요한 정보 부족 또는 fidelity=fail은 not_ready. 정보가 부족하다는 사실조차 판단할 수 없는 자료 누락 또는 readiness=ready인데 fidelity를 검증할 수 없으면 unknown.
4. 연결 시도는 있으나 메시지가 없으면 '무발화로 관측됐으나 telemetry 누락과 구별 못함'을 인정한다. 명시 실패 event가 없는 기록 부재만으로 실제 사용자가 말하지 않았다고 단정하지 않는다.
5. 원문 근거와 저장 행을 직접 읽고 짧은 이유를 남긴다. 모델명이 없는 packet 순서대로 평가하고 모든 판정 확정 전 그룹 집계를 보지 않는다.
6. 같은 기준을 전체 cohort에 적용한다. evaluator는 Codex이며 사람 평가라고 쓰지 않는다. 독립 검토 전 결과는 잠정 audit이다.
