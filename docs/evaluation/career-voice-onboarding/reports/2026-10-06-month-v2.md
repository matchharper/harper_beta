# Career Voice 온보딩 A/B — 최근 30일 재평가

데이터 기준: **2026-09-06 16:00~2026-10-06 16:00 KST**. 실험의 첫 배정 시도는 2026-09-21 18:41 KST이므로, 그 이전에는 비교 가능한 노출이 없다. 첫 온보딩 선택이 통화인 외부 사용자 120명 전수를 포함했고, 첫 선택 이후 24시간이 지난 **113명**을 주 분석으로 삼았다. 첫 연결 실패와 기록 누락도 배정 분모에 남겼다.

## 결론

**온보딩 기본 선택은 GPT-Realtime 2.1을 유지한다. GPT-Live 1을 우선 모델로 전환할 근거는 없다.** 추천 준비에 필요한 정보와 저장 정확성이 첫 통화에서 확인된 비율은 Realtime이 더 높다. Live는 배정 사용자당 음성 경로 비용이 낮고, 성공 확인 1명당 관측 비용도 약 12% 낮다. 다만 관측 누락이 크고 95% 구간이 0을 포함하므로 모델 자체의 확정적 우열이나 전면 전환 승인을 뜻하지 않는다. 배정·배포 변경은 이 평가에서 하지 않았다.

## 첫 통화 품질 — 24시간 성숙 표본

| 판정 | Realtime 2.1 | GPT-Live 1 |
| --- | ---: | ---: |
| 배정 사용자 | 59 | 54 |
| 추천 준비·저장 정확성 확인 | **23/59 (39.0%)** | **13/54 (24.1%)** |
| 정보 부족 또는 중요한 저장 오류 | 11 | 21 |
| 첫 통화 기록 부족으로 판정 불가 | 25 | 20 |
| 그중 중요한 저장 오류 | 6 | 5 |
| 첫 연결 시도 없음 | 4 | 6 |
| 24시간 내 운영상 온보딩 완료 event | 48/59 (81.4%) | 40/54 (74.1%) |

성공 **확인** 비율 차이는 Realtime **+14.9%p**다. Wilson/Newcombe 95% 구간은 Realtime−Live **−2.3%p~+30.8%p**이며 0을 포함한다. 판정 불가를 모두 성공으로 보는 상한은 Realtime 48/59=81.4%, Live 33/54=61.1%다. 이는 실제 성공률의 신뢰구간이 아니라 누락 자료에 대한 범위다. 운영상 완료 event에는 재통화나 채팅으로 완료한 경우가 포함되므로 첫 통화 정보 품질을 대신하지 않는다.

기존 50명 이후 추가된 사용자 가운데 24시간 성숙 표본만 보면 Realtime **12/35 (34.3%)**, Live **8/28 (28.6%)**였다. 관측 방향은 같지만 차이가 더 작고 표본도 작다. 통화 경로와 위임 모델·prompt가 기간 중 바뀌었으므로 전체 결과를 단일 고정 모델의 통제 실험으로 해석할 수 없다.

## 같은 표본의 첫 통화 비용

| 기록 기반 추정 | Realtime 2.1 | GPT-Live 1 |
| --- | ---: | ---: |
| 첫 세션 사용량이 기록된 사용자 | 42/59 | 35/54 |
| 첫 세션 비용 합계 | **$36.94** | **$18.44** |
| 배정 사용자당 | **$0.63** | **$0.34** |
| 성공 확인 1명당 | **$1.61** | **$1.42** |

Live 합계는 **음성 세션 13,576초 × $0.05/분 = $11.31**, 별도 판단 모델 **$7.13**이다. 기간 중 판단 모델로 기록된 `gpt-5.6-terra`는 당시 로그의 추정액을 사용했고, 이후 `gpt-6.1-sol`은 사용량 로그의 토큰 수에 공식 단가를 적용했다. `gpt-6.1-sol`의 현재 내부 로그는 `unpriced`와 $0으로 기록되므로 $0을 비용으로 취급하지 않았다. Realtime은 응답별 기록된 토큰 비용 추정액을 합산했다. [Live 요금](https://developers.openai.com/api/docs/models/gpt-live-1), [Realtime 요금](https://developers.openai.com/api/docs/models/gpt-realtime-2.1), [GPT-6.1 Sol 요금](https://developers.openai.com/api/docs/models/gpt-6.1-sol)

Live의 배정 사용자당 관측 비용은 약 45%, 성공 확인 1명당은 약 12% 낮다. 그러나 첫 세션 사용량이 없는 사용자가 Realtime **17명**, Live **19명**이고, Realtime의 별도 입력 전사 비용과 기타 도구·후속 모델 호출은 합계에서 빠졌다. 더구나 Live에서 음성 사용량은 기록됐지만 판단 모델 사용량은 없는 정보 부족 사례 9건 중 8건은 통화 중 저장 작업이 확인된다. 사용량 로그 부재를 판단 모델 미사용이나 비용 $0의 증거로 볼 수 없다. 따라서 이는 **전체 청구액이 아닌 첫 통화 경로의 불완전한 추정치**다. 특히 성공 확인 1명당 비용은 실패·중단된 사용자에게 쓴 금액을 포함해 성공 확인 수로 나눈 회계상 비율이며, 추가 성공 1명의 한계비용이 아니다. 이 자료로 양쪽의 실제 성공당 총비용 차이를 확정할 수는 없다. [Realtime 전사 별도 과금](https://developers.openai.com/api/docs/guides/voice-latency-cost)

## 결과 차이가 생긴 지점 — 탐색적 분석

| 판정 가능한 첫 통화 34건씩 | Realtime 2.1 | GPT-Live 1 |
| --- | ---: | ---: |
| 추천 정보가 충분함 | 28 | 18 |
| 추천 정보가 부족함 | 6 | 16 |
| 중요한 저장 정확성 오류 | 6 | 5 |

차이는 주로 **필요한 역할·지역·보상·제약을 첫 통화 안에 확인했는가**에서 났다. 저장 정확성 오류의 건수는 비슷하다. Live의 정보 부족 사례에는 사용자가 통화를 마치기 전에 조건이 미확인 상태였는데도 충분히 확인했다고 응답하거나 대화를 마무리한 통화가 있다. 사용자 요청으로 짧게 끝난 통화와 종료 기록이 없는 통화도 섞여 있다. 따라서 이 패턴을 음성 모델 자체의 추론 성능만으로 귀속할 수 없다. Live는 음성 프런트엔드와 별도 판단 모델을 쓰는 경로이고, Realtime은 세션에서 직접 전체 지침과 도구를 받는다.

기간별로 보면 **10월 2일 KST 전** 성공 확인은 Realtime 19/41, Live 9/39였고, **10월 2일 이후**는 Realtime 4/18, Live 4/15였다. 뒤쪽 33명에서는 격차가 보이지 않는다. 이 분할은 출시 변경을 살피기 위한 사후 탐색이며 각 표본이 작다. 기간 중 공통 prompt와 통화 동작이 바뀌었고, Live의 별도 판단 모델도 바뀌었다. 최근 격차 축소의 원인을 특정 변경 하나로 확정할 수 없다. 전체 주 지표의 Fisher 양측 검정도 p=0.108이고 95% 차이 구간이 0을 포함한다. 판정 가능한 통화만 골라 보는 수치는 기록 가용성에 따른 선택 편향이 있으므로 독립적인 승리 판정이 아니다.

## 판정과 재현

- 기존 `pilot-v1`의 성숙 사용자 40명은 당시 동결한 첫 통화 packet과 판정을 그대로 사용했다. 새로 성숙한 기존 사용자와 신규 사용자 80명 중 발화가 있는 48명은 모델명을 숨긴 `pilot-v2` packet으로 직접 검토했고, 첫 사용자 발화가 관측되지 않은 32명은 `unknown`으로 두었다. 1차 판정 전체를 확정한 뒤 그룹을 결합했다.
- 이후 전체 발화 재검토에서 한 사례의 축약 자료에 빠진 명시 선호를 확인해 `not_ready`에서 `ready`로 정정했다. 이는 **그룹을 본 뒤의 비블라인드 판정 수정**이다. 최초 `gold-v2.json`은 보존하고, 변경 이유·시각·검토자를 적은 `gold-v2-labels-v2.json`을 최종 판정으로 사용한다. `pilot-v2`는 사례가 추가되고 성숙 상태가 바뀐 새 dataset version이며, 평가 기준은 `rubric-v1.md`를 유지했다. 독립적인 사람 검토는 아직 없다.
- 원본 production snapshot, case packet, 세션별 사용량과 상세 근거는 ignored `private/`에 owner-only 권한으로 저장했다. 공개 파일에는 계정·대화·이력서 원문을 넣지 않았다. production 조회는 GET-only였고 추가 외부 평가 모델을 호출하지 않았다.
- 재현: `scripts/evalCareerVoiceOnboarding.ts`의 `capture v2`, `packets v2`, `summarize v2 labels-v2`, `cost-capture v2`, `cost-summarize v2 labels-v2`. 동결된 입력·판정·사용량의 해시와 최종 집계는 `manifest-v2.json`, `gold-v2-labels-v2.json`, `summary-v2-labels-v2.json`, `cost-manifest-v2-labels-v2.json`, `cost-summary-v2-labels-v2.json`에 있다.

## 남은 불확실성

첫 통화 사용자 발화가 없는 성숙 사용자 45명의 실제 무음·연결 실패·telemetry 누락을 구별할 수 없다. 원음의 인식 오류, 음성 자연스러움, 지연과 끼어들기 경험도 이 텍스트 평가로는 판정하지 못한다. 당시 모델명·prompt·위임 경로의 변경이 통제되지 않았고, 기존 40건은 이전 Codex audit 판정을 승계했다. 독립 재판정과 누락된 session telemetry, 전체 청구 비용 확인 전까지 이 결과는 **Realtime 우선의 운영 판단**에 사용한다.
