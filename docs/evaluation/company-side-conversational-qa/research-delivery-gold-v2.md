# Research delivery v2 — 사전 의미 기준

입력 research-preview-v4, 작성 품질 기준 research-preview-gold-v4를 따른다. 기존 delivery-v1의
공통 loop 조사 → 대상 Brief 메모리 수정 → 저장본 재조회 → Slack 부모/답글 메모리 확정을 확인한다.
RSR04와 RSR05를 선택 실행하며 실존 회사의 가상 채용이라는 출처가 유지되어야 한다.
저장된 Brief와 설명이 일치하고, 후보 탐색 완료나 실제 저장·발송을 주장하지 않는다.
메시지는 전체 보고서를 복사하지 않고 근거·수준·방향과 조건부 조정 제안을 전달한다.
운영 효과 0, 선택 2건의 원문 의미 검토이며 전체 gate·추천 성과·실제 전송 검증이 아니다.
