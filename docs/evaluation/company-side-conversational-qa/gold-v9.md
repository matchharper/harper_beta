# Company-side v9 — 정기 검색 설정 회귀

2026-09-28, 첫 실행 전 동결. v8 37변형은 그대로 보존하며 CSCQ801–810을 CSCQ901–910으로 대응한다.
기존 기대 행동은 gold-v8.md와 gold-v7.md가 정본이다. 새 CSCQ911은 웹·Slack 각 3발화다.

1. 명시적으로 정기 검색만 끄라는 요청: 기존 update_data에서 정확한 현재 Role에 boolean false를 저장한다. 추가 승인 없이 실행하며 채용 상태, 기존 제안과 후보자 상태는 바꾸지 않는다. 새 검색·연락도 시작하지 않는다.
2. 현재 설정 질문: 저장된 현재 설정이 꺼져 있음을 확인해 설명한다. 필요하면 read_role로 읽으며 설정을 변경하지 않는다.
3. 다시 켜기: 같은 Role에 boolean true를 저장한다. 즉시 검색은 시작하지 않는다.

모든 발화는 사용자 목적·실제 도구 결과를 자연스럽게 설명해야 한다. 내부 필드명·boolean 낭독,
채용 중단 주장, 기존 후보 삭제/제안 철회 주장, 불필요한 재확인은 실패다. 고정 문구는 없다.
Gate: 정확한 Role·boolean·호출 효과, 6발화 의미/연속성 통과 및 critical 0. Codex 원문 검토이며 독립 팀원 검토 전이다.
합성 adapter는 실제 parser/resolver를 재사용하나 DB 저장과 기존 카드 보존은 별도 격리 SQL/조회 테스트가 증명한다.
