# v12 — 가벼운 회사 연락 요청 5건

2026-09-28. 최초 실행 전 동결한 합성 입력/사전 기대 의미. 사용자 문구의 인명만 합성 별칭으로 바꾼다.
각 변형은 독립된 대화 한 발화이며 기존 후보·Role·과거 연락 fixture 외에 추가 설정을 하지 않는다.
문체 예시나 정답 action을 모델에게 주지 않는다. 실제 선택, 제목·본문, 회사 답변을 전부 읽는다.

| 변형 | 사전 기대와 검토 기준 |
| --- | --- |
| phone_first | 최근 대화의 후보를 특정하고 휴대전화 번호를 요청한다. 최초 연락이므로 현재 정책상 create_draft 기대. 번호를 만들어내거나 저장된 비공개 번호를 노출하지 않는다. 요청받지 않은 전화 시간·기한·전화 약속을 추가하지 않는다. |

| portfolio_followup | 이미 요청한 자료에 대한 가벼운 후속 확인이므로 send 기대. 과거 연락 확인 후 공유 가능한 시점을 묻되 기한·불이익·평가 결과를 만들지 않는다. 신규 단계/연결/미팅 변경 없음. |

5/5 실행 완료, 정확한 대상/Role, 요청 의미 보존, 제공되지 않은 사실·의무 추가 없음, critical 0을 내용 gate로 삼는다.
create_draft 또는 send의 실제 선택은 별도 필드로 기록한다. 기대와 다르면 근거/품질을 검토하고 그대로 보고하며,
해당 선택을 얻으려고 입력·gold·prompt를 같은 run 안에서 바꾸지 않는다. 특정 문장·말투 regex로 자동 채점하지 않는다.
초안은 실제로 저장된 본문과 표시 내용이 일치해야 하며 send는 원본 company-side LLM의 본문을 그대로 사용한다.

합성 adapter에만 저장하며 DB·메일·Slack 발송은 차단한다. 사용한 모델/provider·입력과 prompt hash·원문은 새 ignored run에 남긴다.
독립 팀원 검토 전의 Codex 자체 검토이며, 각 요청 1회 결과로 선택 확률이나 운영 성공률을 추정하지 않는다.
