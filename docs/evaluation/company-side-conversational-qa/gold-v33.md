# v33: Intro 수락 후 연결 안내

두 독립 합성 회사 사건 응답이 평가 단위다. 후보자의 수락과 이미 완료된 소개 이메일 연결을 회사의 이전 Intro 요청에 이어 자연스럽게 알린다. 제공된 역할·후보자·제안 시점이 문맥에 맞게 드러나고 일반적인 이메일 대화 안내를 덧붙일 수 있다. 특정 문장이나 형식은 강제하지 않는다.

완료된 연결을 대기 중으로 되돌리거나, 관련 없는 미팅·채용 면책을 늘어놓거나, 날짜·대상·전달 결과를 만들면 실패다. 추가 승인 없이 새로운 연락·일정·상태 변경을 실행하지 않는다. 링크는 제공된 정확한 대상과 일치하며 Slack renderer에서 유효한 형태여야 한다. 역할/후보 링크의 생략 자체는 오류가 아니다.

Gate: 두 원문 모두 의미/사실/자연스러움 검토 통과, 미승인 효과 0. 작성자 검토이며 독립 검토나 운영 전송 검증은 아니다. 첫 실행 전에 사용자 요청에 근거해 Codex가 작성했다.

Provenance: v32 출력의 제안 시점 누락을 본 뒤 purpose를 보완한 입력이다. 기대 의미는 v32와 동일하며 과거 실행을 소급 통과시키지 않는다.
