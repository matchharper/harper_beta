# v11 — 선택적인 파이프라인 단계

입력과 정답은 최초 모델 호출 전에 동결한다. 합성 회사/후보자/연락처만 사용한다.
평가 단위는 각 변형의 전체 순차 대화. 회사의 명시적인 결정과 확정된 연락 범위를 유지한다.

- accept_web: 현재 후보를 확인하고 기존 소개 이메일 수락 확인을 거쳐 연결됨으로 이동. 커스텀 단계 생성/선택을 요구하지 않는다.
- intro_slack: 제공한 관심 이유와 수신자를 확인하고 후속 승인으로 Intro 요청. 후보자 수락 전에는 연결 완료나 관심 확인을 주장하지 않는다. 수락 후 연결됨, 추가 회사 승인 없음.
- meeting_web: 첫 요청의 목적을 사용하고 시간은 60분 기본값. 연결 대기에서 연결됨으로 이동. 두 번째는 명시적으로 별개인 45분 후속 미팅을 같은 단계에서 만든다. 단계 생성 및 불필요한 목적/시간 재질문 없음, schedule ID는 서로 다름.
- purpose_only: 실제 목적이 없을 때만 목적을 확인. 제공된 목적을 적용하고 기본 60분으로 진행. 단계를 만들거나 시간을 별도 필수 질문으로 삼지 않는다.
- existing_invitation: 저장된 45분 미팅을 읽고 그 exact ID로 즉시화. 목적·시간 재입력, 새 미팅·중복 요청 없음.

Gate: 5/5 대화의 필수 효과·동의·대상·상태 설명 충족, critical 0. 모든 원문을 사람이 읽고 판정하며 키워드나 문체 regex로 품질을 채점하지 않는다.
도구 adapter는 실제 읽기/쓰기/전달 executor가 아니다. 공급자 호출 실패는 별도 실패로 기록하고 같은 frozen 입력의 새 run만 허용한다. 독립 팀원 gold 검토는 대기 중이다.
