# 실제 회사 조사 미리보기 관찰

사용자가 요청한 실제 회사 한 곳의 역할·Brief·일부 대화와 제한된 검토 기록을 read-only로 캡처했다. 운영 원문, 회사 식별자, 모델 출력은 ignored private/runs에만 보존한다. 회사/후보자 저장·발송·추천·활성화·배포는 하지 않았다.

## 실행

- `20261015-role-research-real-company-v1-r1`: 조사 도구 16회, completion 5회. 최종 문서 작성이 일반 대화의 4,000토큰 한도를 소진해 실패했다. 원래 실패를 보존한다.
- `20261015-role-research-real-company-v1-r2`: 동일 입력, 조사 전용 16,384토큰 한도로 재실행. 130,550ms, 도구 20회, completion 5회, 최종 stop. 모든 completion이 실제 gpt-6.1-sol/medium이며 source hash 변동이 없었다. 공개 검색은 live이므로 두 실행의 웹 자료는 다르다.
- 기존 research runner에 실제 snapshot provenance와 회사 공통 request를 전달하도록 보완했다. 조사 함수에서만 출력 한도를 지정한다. 일반 회사 대화 설정과 채용 시작 경로는 변경하지 않았다.
- 네트워크는 OpenAI Responses와 Exa search/contents뿐이다. Responses store:false, temperature 생략. 모델 실행 프로세스의 DB와 발송 경로는 차단했다. 호출 진입점 검색에서도 manual runner와 테스트 외 연동이 없다.
- 경계 테스트 5개 통과. 첫 두 테스트 실행은 필수 환경변수 없이 import해 초기화에서 실패했고, 실제 비밀키 대신 dummy 설정을 제공해 검증했다.

## 원문 검토

실제 공식 사이트에서 인물을 발견하고 공개 프로필·개인 원본으로 이전 경력을 확인했다. Brief에는 수준과 비교 책임 범위를 먼저 적고, 출신은 예시로 사용했다. 강한 가산과 보조 가산의 실제 검토 효과, 기존 기준과 제안의 구분, 조건부 향후 조정 문장을 관찰했다.

전체 결과를 자동 적용 가능하다고 판정하지 않는다. 회사 공통 학교·스타트업 문장을 해당 역할의 Hard constraints로 옮겼으나 그 적용 범위는 별도 확인이 필요하다. Slack 답글도 길고 제한 설명의 비중이 높다. 생성 원문은 교정하지 않고 사용자에게 그대로 제공한다.

추가 대화 도구는 캡처 범위 밖이라 실패했다. 한 공개 프로필은 조회됐지만 누적 도구 결과 예산 때문에 상세 내용이 모델에 전달되지 않았고 최종 문서는 이를 미확인으로 남겼다. 전체 회사 이력·팀 구성 조사나 운영 추천 품질 검증으로 해석하지 않는다. 독립 gold 없는 작성자 1건 관찰이며 frozen v3 gate와 합산하지 않는다.

원문에서 Brief 코드 블록과 회사 메시지 섹션만 별도 파일로 추출해 열람 편의를 제공했다. 문구를 다시 쓰거나 deterministic 출력 교정은 하지 않았다.
