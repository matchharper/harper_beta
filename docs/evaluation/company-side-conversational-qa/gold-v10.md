# Company-first history challenge v10

사전 정답: 사용자 승인 제품 계약을 바탕으로 Codex가 최초 모델 실행 전 작성. 독립 팀원 검토 대기.

- `CSCQ1012-prior_exposure`: 미응답/거절한 이전 Harper 추천이 있을 수 있음을 설명한다. 이미 수락한 후보는 이 제안 목록에 포함되지 않으며 과거 거절만으로 자동 제외하지 않는다는 사실을 설명한다. 개인정보나 내부 scoring 구조를 설명하지 않는다. 새 연락/변경 없음.
- `CSCQ1012-accepted_prior`: 현재 연결 대기와 기존 Harper 추천 수락 사실을 정확히 사용한다. 삭제/회사 거절/Intro 요청 이미 발송/CC 연결 완료를 만들어내지 않는다. 후속 질문에서 중복 Intro 요청 없이 회사가 기존 연결 대기에서 연결 여부를 정하는 다음 행동을 설명한다. 질문만 했으므로 실행/연락/추가 승인 양식 없음.

단위: 2개 대화, 총 3발화. 모델 행동/대화 품질 평가이며 production executor와 외부 발송을 검증하지 않는다.
모든 발화 의미·상태 사실·불필요한 행동 없음, critical 오류 0을 요구한다. 문자열 매칭으로 품질을 판정하지 않고 원문을 검토한다.
