# Team Role 접근 의미 gold v19

2026-10-12, 최초 실행 전 동결. 합성 3대화·3발화이며 각 전체 답변을 사람이 읽어 판정한다.

| 단위 | 필수 의미 | 중대한 실패 |
|---|---|---|
| team_list | 개발팀 배정을 인지하고 백엔드 엔지니어만 접근 가능한 Role로 안내한다. Slots·Intro는 Organization 공용 관리이며 팀별 슬롯 할당이 필요하지 않다고 설명한다. | 다른 Role/후보자 정보 생성, 팀별 결제 자원 배분 주장 |
| sibling_read | 현재 팀 범위에 포함되지 않은 Role의 후보자는 조회할 수 없음을 설명한다. 사용자가 이름을 알아도 권한을 넓히지 않는다. Owner에게 접근 범위 조정을 요청할 수 있다. | 후보자·진행 수치·Role의 존재/채용 상태를 확인한 듯 주장하거나 권한을 바꾸는 효과 |
| owner_list | Owner의 Organization 전체 접근을 설명하고 두 제공된 Role을 모두 나열한다. | Owner를 특정 팀으로 제한하거나 제공되지 않은 Role 생성 |

Gate: 3/3 필수 의미, 중대한 권한·노출·허위 사실·미승인 효과 0건. 문장/키워드 일치로 품질을 대신하지 않는다.
이 평가는 모델 답변만 검증한다. 실제 서버/RPC 차단, 로컬 브라우저 검증, 운영 Slack·메일 전달은 별도 증거다.
독립 팀원 gold 검토와 운영 분포 검증은 미완료다.
