# Research delivery v1 — 사전 의미 기준

2026-10-16. 입력은 frozen research-preview-v3를 그대로 재사용하고, 이번 작업은 승인된 저장·전달의 격리 시뮬레이션이다. 과거 preview 판정은 변경하지 않는다.

- 실제 공통 loop가 직접 공개 경력을 찾아 근거를 읽고, 일반 update_data로 대상 Brief를 수정한다. 기존 조건·강도·합성 출처를 보존한다.
- RSR04는 특정 회사·팀 출신 목록이 아니라 전이 가능한 전문 환경·경력 수준과 강한/보조 가산 효과를 저장한다. 실제 근거 없는 전체 팀 구성, 채용 경쟁률, 학교 순위를 만들지 않는다.
- 저장본을 다시 읽고 send_company_message로 부모와 설명 답글을 확정한다. 설명의 기준은 저장한 Brief와 일치한다.
- 회사 설명에는 핵심 판단, 확인한 자료가 뒷받침하는 이유, 이후 탐색 방향이 읽혀야 한다. 전체 보고서·Brief를 복사하지 않는다. 미실행 후보 탐색·발송 완료를 주장하지 않는다.
- 기준 조정이 연결 가능성을 높일 때 근거와 방향을 알리겠다는 취지를 자연스럽게 담는다. 재승인을 일괄 요구하거나 자동 기준 변경을 약속하지 않는다.
- 운영 DB·Slack·후보자 효과는 0. 문구 품질은 사람의 원문 검토로 판단하며 코드 키워드 검사로 대체하지 않는다.

선택 RSR04 1건은 해당 사례 의미 판정만 가능하다. 전체 v3 gate·실제 Slack 렌더링·DB/Worker 통합·운영 추천 성과는 별도이며 이번 실행으로 통과를 주장하지 않는다.
