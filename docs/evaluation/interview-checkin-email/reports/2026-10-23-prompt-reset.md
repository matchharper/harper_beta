# 인터뷰 전후 이메일 프롬프트 재검토

2026-10-23. 로컬 수정과 작성 품질 확인이며 배포·예약 발송 구현 완료를 뜻하지 않는다.

사용자에게 보낸 회사 사후 이메일이 지난 약속을 앞으로 있을 일정처럼 설명했다. 발송 전 assistant 검토에서도 놓친 오류다. 길이는 문제가 아니며, 기존 검토의 길이 중심 판단은 철회한다.

## 확인된 문제와 수정

| 문제 | 수정한 책임 원본 |
| --- | --- |
| 후보자 사후 입력에 실제 실행 시각 12:14와 가상 연락 시각 15:00이 함께 있었다. | Career 공통 prompt builder가 선택적 `requestTime`을 받게 하고 미리보기 시각을 여기에 전달한다. 기본 실행은 기존 현재 시각을 쓴다. 별도 사실 JSON의 중복 현재 시각은 제거했다. |
| 회사 prompt는 `runtime_context.current_time_kst`를 읽도록 했지만 이메일 adapter는 그 위치를 제공하지 않았다. | 공통 회사 이메일 adapter가 기준 시각과 수신 언어를 runtime context에 제공한다. 현재 checkout의 공통 시간 포맷과 timezone 표기를 그대로 사용한다. |
| 회사의 공통 지침은 같은 채팅·마무리 생략을 요구하고, 이메일 지침은 인사·끝인사를 요구했다. | 공통 목소리는 채널에 중립적으로 정리했다. 인사·끝인사·본문 형식은 이메일 surface가 담당하며, 해당 지침을 전체 공통 지침 뒤에 한 번 배치한다. |
| 후보자 이메일 채널 지침이 두 번 반복됐고, 미리보기에 무관한 온보딩 전환·기회 탐색 상세 지침까지 들어갔다. | 이메일 adapter의 채널 지침은 한 번만 포함한다. 미리보기는 기존 capability resolver의 작성 전용 도구 범위와 기존 온보딩 안내 제외 옵션을 사용한다. 별도 writer system을 만들지 않는다. |
| 단계별 목적에 문체·형식 지시까지 중복돼 있었다. 미관측 boolean이 불필요한 불확실성 설명을 유도했고, 다음 일정 요청의 수신자도 모호했다. | 목적은 연락 의도로 줄였다. 입력에는 약속·배경·최근 대화·실제 소감·가능한 도움을 제공한다. 후보자에게 시간 선택 요청을 보낼 수 있다는 기능 사실을 명시한다. |

이 문제들은 실제 조립 입력에서 확인했다. 특정 지시 하나가 이전 문장을 만들었다는 인과 실험은 하지 않았다.

## 정리한 호출 계약

일반 talent-side/company-side prompt와 completion helper를 그대로 사용한다. 원본 LLM에 수신자, 하나의 기준 시각, 약속, 공유 가능한 상대 배경, 최근 대화와 다음 도움의 실제 범위를 제공하고 아래 목적을 전달한다.

- 사전: “다가오는 인터뷰를 리마인드해 주세요. 상대의 관련 배경과 참여 링크를 맥락에 맞게 담아 주세요.”
- 사후: “인터뷰 뒤 안부를 전하고, 최근 대화에 이어 소감이나 필요한 다음 도움을 챙겨 주세요.”

공통 이메일 지침은 수신 언어, 자연스러운 인사·끝인사, 현재 연락 이유, 사용할 수 있는 링크와 사실·권한 경계를 맡는다. 분량·문단 순서·고정 문장·필수 후속 질문은 정하지 않는다. 시간 경과와 실제 참석·결과는 구분하며, 이미 받은 소감과 최신 의사를 이어받는다. 출력 문장을 검사·교정하는 키워드 규칙이나 추가 작성 모델은 없다.

## 실제 재검증

- 기존 frozen v4 5건을 같은 `gpt-6-luna`로 재실행했다. 첫 수정에서 시점 오류는 해소됐으나 회사 끝인사 누락과 영어 사례의 언어 이탈을 발견했다. 지침 배치와 이메일 작성 책임을 수정한 재실행에서 이 문제를 해소했다.
- 추가 frozen v5 3건에서는 자정 경과·영어 사후·이미 받은 소감을 확인했다. 소감을 이미 받았는데도 다시 묻는 문제와 다음 일정 요청 대상의 모호함을 기록하고, 공통 대화 연속성 지침과 입력 계약을 수정했다.
- 최종 frozen v6는 위 8개 상황을 유지하고 목적·기능 설명만 정리했다. `review-20261023-v6-final`에서 **8건 모두 실제 gpt-6-luna**로 작성했다. 후보자 reasoning은 xhigh, 회사는 medium이며 모델 fallback을 허용하지 않았다.
- 전체 원문을 직접 읽어 지난 약속의 미래 시제 오류, 상대 혼동, 수신 언어 오류, 없는 완료·발송 주장, 최신 연락 보류 의사 위반이 없음을 확인했다. 사전 3건은 제공된 참여 링크를 보존했다. 자정 경과 사례는 전날 밤을 가리켰고, 이미 소감을 받은 사례는 반복 질문 없이 최신 의사를 이어받았다.
- 변경 경로의 자동 검사 **15개 통과**: 기준 시각 전달, 채널 지침 중복 방지, 기존 데이터·대화 보존, 공통 회사 prompt 조립. 문체·시제 판단은 자동 문자열 검사로 대체하지 않았다.
- 최종 생성의 운영 DB 접근·도구 실행·추가 이메일 발송은 모두 0건이다. 원문, 조립 prompt, 모델 metadata, prompt fingerprint와 직접 검토 기록은 ignored `runs/`에만 보존한다.

## 검증 한계와 적용 범위

소규모 합성 작성 검증이며 독립된 사용자 품질 승인을 뜻하지 않는다. 후보자 사후 문장에는 조심스러운 조건 표현이 일부 남아 있다. 이를 금지어·문장 교정으로 없애지는 않았다.

공통 prompt builder/adapter와 미리보기 호출을 수정했다. 인터뷰 시작 2시간 전·예정 종료 15분 후의 자동 실행, 운영 권한 조회, 취소·변경 경쟁, 전달 멱등성, 답장 연결은 이번 검증 대상이 아니다. 운영 모델 설정·DB·스케줄러를 변경하거나 배포하지 않았다.
