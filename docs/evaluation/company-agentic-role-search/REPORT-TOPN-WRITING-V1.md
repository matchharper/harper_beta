# 대화 검색 조회·Top N·설명 작성 재검증 (2026-10-23)

> 후속 변경: 이 보고서의 ‘기존 추천 제거의 남은 동작 차이’는 이후 새 Top N으로 전체 미응답 목록을 교체하도록 수정했다. [최신 구현·검증 범위](AUDIT-2026-10-23.md)를 참고한다. 아래 실제 모델 실행 수치는 수정 전 선정·설명 실험으로 보존한다.

대화 검색에서 다단 LLM 후보 비교를 제거하고, 기존 2차 mutualFit 내림차순으로 Top N을 선택한 뒤 후보별 설명을 병렬 작성하도록 수정했다. 정기 검색의 후보 비교·작성 계약은 이번 변경 대상이 아니다. 운영 DB 저장·발송·배포는 실행하지 않았다.

구조 검증에서 입력·평가 hash가 그대로였고, 100개 criteria의 원래 숫자 점수와 라벨이 모두 보존됐다. 모델 출력에는 새 등급·finalFit 필드가 없다. 대화 검색의 별도 `final_fit=null`은 의도된 계약이다.

## 조회 진단은 별도의 현재 DB 관찰

같은 role·schema와 기존 가입 cutoff를 사용했으나 현재 DB의 원문 수정은 가능하다. 새 조회 인원을 frozen 선정 집합에 섞거나 재평가하지 않았다.

| 지표 | Designer 역할 | FDE 역할 |
| --- | ---: | ---: |
| 기존 frozen 조회 수 | 3,503명 | 3,554명 |
| 보완 planner의 새 조회 수 | 769명 | 2,528명 |
| 기존 1차 통과자 중 다시 조회됨 | 95 / 139명 | 1,792 / 2,051명 |
| 기존 점수 Top 10 중 다시 조회됨 | 7 / 10명 | 10 / 10명 |
| planner·조회 진단 경과 시간 | 80.04초 | 143.92초 |

실행기는 삭제 계정·온보딩·공개·내부 추천 수신·회사별 차단·snapshot cutoff를 확인한다. 요청의 신규/미평가/전체 범위와 해당 기준 버전, 명시 ID, 요청 예산도 적용한다. 기본 조회 예산은 5,000명이며 실제 조건에 맞는 수만 반환한다. 2차 전체 재평가는 기존 1차 통과 집합을 사용한다. 기존 미응답 추천도 재평가 대상에서 단순 조회 누락되지 않게 포함한다.

새 조회는 실제 업무 관련 필터를 만들지만, 이것만으로 누락과 과다 조회가 해결됐다고 판단할 수 없다. 특히 Designer의 인접 경력 후보 누락은 미해결이다. 기존 점수 Top 10 역시 인간이 검수한 정답 집합은 아니므로 위 비율은 재현율 정확도 지표가 아니라 손실을 드러내는 진단이다.

## 출력 내용 검토와 한계

최종 두 역할의 기준 설명·추천 이유를 직접 읽었다. 실제 업무 근거와 미기록 조건을 구분하는 문장이 많았으며, 중복 평가에 의한 라벨 변경은 없어졌다. 다만 미기재를 반복하는 표현과 필드 사이의 일부 선호 설명 중복이 남는다. 전 문장의 사실 정확도를 독립적인 gold나 별도 심사 모델로 인증하지 않았다.

일부 높은 평가의 근거는 비공개 Memory에 있고, 회사용 writer에는 그 Memory가 전달되지 않는다. 실제 원문 확인에서 비공개 고객 업무 경험 또는 근무 의사가 점수를 뒷받침하지만 공개 프로필에는 없는 사례가 있었다. 이 경우 공개 설명의 “미확인”과 높은 점수의 차이를 곧바로 평가 오류라고 판정할 수 없다. 그렇다고 근거를 새로 만들어 설명하거나 비공개 내용을 노출해서도 안 된다. writer는 공개 근거의 한계를 설명한다.

**기존 추천 제거의 남은 동작 차이:** Top N 밖으로 밀렸다는 이유만으로 기존 추천을 없애지 않는다. 이번 실행의 새 1차 제외 명령은 피드백 없는 기존 추천을 내릴 수 있고, save/pass/accept/intro 등 기존 결정은 보호한다. 그러나 **2차만 재평가했을 때 점수가 낮아진 기존 미응답 추천을 자동으로 내리는 판단은 현재 없다.** 기존 후보의 설명을 갱신하며, 임의 합격선을 추가하지 않았다. 따라서 원래 요청의 “2차 재평가로 기존 전체 추천 목록이 자연스럽게 변경”까지 모두 완료했다고 보고하지 않는다.
