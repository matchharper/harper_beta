# 45/35/10/10 정렬 가중치 비교

2026-11-05. 사용자가 지정한 가중치로 동일한 v2 50명·265공고·438개 좋아요/싫어요 쌍을 다시 정렬했다. 기존 5개 실험군의 모델 출력을 그대로 재사용했으며 추가 API 호출·비용은 0이다. 실제 서비스의 가중치와 동결된 입력·정답은 변경하지 않았다.

후속 감사에서 사후 프로필·설정을 통한 간접 정보 누출을 배제하지 못했다. 직접적인 평가 대상 피드백은 모델에 넣지 않았지만, 아래 수치는 누출 검증을 통과한 성능이나 최적 가중치의 근거가 아니다. [50명 실험의 입력 감사 정정](2026-11-05-v2-50-users.md)을 함께 읽는다.

가중치 순서는 mutualFit / candidateInterest / companyInterest / roleFit이다. 비교식은 각각 `0.30M + 0.50C + 0.10E + 0.10R`, `0.45M + 0.35C + 0.10E + 0.10R`이며, 이전 평가와 동일하게 별도 constraint penalty 없이 비교했다.

지표는 사용자마다 좋아요 공고가 싫어요보다 높은 비율을 계산한 뒤 50명을 동일 비중으로 평균한 값이다. 동점은 0.5다. 95% 구간은 같은 사용자의 두 가중치 결과 차이에 대한 paired bootstrap 2,000회(seed 20261106)다.

| 평가 방식 | 30/50/10/10 | 45/35/10/10 | 변화 | 변화의 95% 구간 |
| --- | ---: | ---: | ---: | ---: |
| 기존 v6 방식 | 60.41% | 59.81% | -0.60%p | -3.10 ~ +0.92%p |
| 기존 v6 + 예상 연봉 | 65.44% | 65.92% | +0.48%p | -0.24 ~ +1.31%p |
| 새 v8 질문만 | 62.76% | 62.53% | -0.23%p | -4.36 ~ +5.06%p |
| 이전 v7 변경안 + 예상 연봉 | 66.95% | 64.46% | -2.48%p | -7.62 ~ +1.01%p |
| 불확실성 명시 v8 변경안 | 64.02% | 63.72% | -0.30%p | -3.23 ~ +2.67%p |

불확실성을 명시한 현재 v8 변경안은 **64.02% → 63.72%, −0.30%p**다. 사용자별 피드백 순위 일치도는 3명 개선·7명 악화·40명 동일이다. 동일하다는 것은 해당 지표가 같다는 뜻이며 전체 공고 순서가 완전히 같다는 뜻은 아니다. 438쌍의 판정은 4쌍 개선·8쌍 악화·426쌍 동일이고, 모든 쌍을 같은 비중으로 세면 66.21% → 65.30%다.

45/35/10/10 아래에서 v8 변경안은 같은 가중치의 기존 v6보다 +3.91%p 높지만, 차이의 95% 구간은 −5.45 ~ +13.73%p다. 다섯 방식 중 관측 최고값은 기존 v6 + 예상 연봉의 65.92%다. 모든 가중치 변경 차이의 구간이 0을 포함하므로, 이번 결과로 45/35/10/10이 더 낫다고 결론 내릴 수 없다. 현재 v8에서는 실질적인 차이가 작았다.

기존 표본을 이미 관찰한 뒤 사용자가 지정한 가중치를 비교한 후속 분석이다. 새 holdout이나 가중치 최적화가 아니다. 과거 입력 복원, 46명의 재구성 Behavior Context, 추정 연봉 111건의 사후 보강, 선택된 피드백 표본이라는 한계는 [50명 실험 보고서](2026-11-05-v2-50-users.md)와 같다.
