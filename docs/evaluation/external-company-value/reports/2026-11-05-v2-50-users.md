# 예상 연봉 불확실성 명시 — 50명 과거 표본 비교

2026-11-05. 로컬 구현·미배포. 이전 19명 실험을 보존하고 별도 50명 표본을 동결했다. **사용자별 순위 일치도는 기존 v6 60.41%, 이전 v7 변경안 66.95%, 새 v8 변경안 64.02%**다. 연봉 추가가 악화된다는 앞선 작은 표본의 결과는 이번 표본에서 재현되지 않았다. 불확실성을 더 명시한 문구가 점수 품질을 개선했다는 근거도 확보하지 못했다. 모든 주요 차이의 95% 구간이 0을 포함한다.

**후속 입력 감사 정정:** 아래 수치는 누출 검증을 통과한 성능으로 해석할 수 없다. `profile_row_unchanged`는 추천 당시와의 동일성이 아니라 10월 17일·18일 추출본 사이의 동일성을 뜻했다. 50명 모두 프로필 최종 수정 시각이 추천 이후였다. 평가 대상 좋아요·싫어요와 그 사유를 직접 전달하지 않은 것은 확인했지만, 상위 복원 과정에서 사용한 사후 프로필·설정을 통한 간접 누출 가능성을 배제하지 못했다. 실제 피드백이 반영됐다는 증거는 아니며, 동결 입력·정답·점수는 수정하지 않았다.

## 변경

`candidateInterest`·`mutualFit`의 기존 연봉 설명을 수정했다. 모델 추정은 대략적이고 검증되지 않았으며 회사·지역·직급에 따라 크게 틀릴 수 있다. 정밀해 보이는 숫자와 범위를 회사의 실제 급여 하한/상한이나 예산으로 간주하지 않는다. 같은 보상 구성에 대해 JD의 회사 공개 보상이 있으면 이를 우선한다. 추정치만으로 hard constraint 충돌을 확정하지 않는 기존 원칙은 유지한다.

모델이 받는 각 예상 기본급에도 `rough prediction; may be substantially inaccurate`를 명시했다. 공개 급여 projection과 구분하며 성과급·주식은 제외한다. prompt version은 `external-fit-questions-v8-salary-uncertainty`다. 새 runtime 입력을 실제 provider 요청으로 렌더링해 검사했다. 가중치는 30/50/10/10으로 유지했다.

## 표본과 사전 고정 설계

- 과거 추천 기간: **2026-09-09~2026-10-08**, 50명·50개 추천 run·265공고. 좋아요 141건, 싫어요 124건, 같은 run 내 비교쌍 438개. 모든 사용자가 양쪽 반응을 남겼다.
- 출처: private `harper_eval`의 고정 commit `8b4eadeffa2f63149bce408f6fef611316b74fe5`, 기존 cases·scoring-inputs-v1·pairs-v1. 원본 4개 파일의 SHA-256을 확인했다.
- Brief fingerprint 일치, 원본 prep의 프로필·경력·학력 비교 flag, 같은 run 내 유효한 양쪽 반응을 가진 229명 중 사용자 ID의 사전 고정 hash 순으로 50명 선정. 이 비교 flag는 사후 추출본 간 비교이며 추천 당시 프로필과의 동일성을 증명하지 않는다. 사용자마다 가장 최근 eligible run 하나를 선택했다. 회사·점수·연봉·거절 사유로 고르지 않았다.
- 기존 7일 피드백 규칙과 이미 지원/마감 제외 규칙을 유지했다. 438쌍은 각 사용자의 선택된 긍정×부정 전체 조합과 일치한다. feedback·reason·과거 점수·노출 순위는 모델에 넣지 않았다.
- **50명 모두 당시 실제 API 입력이 완전하게 보존된 것은 아니다.** 프로필·Brief와 보존된 카드로 입력을 복원한 기존 prep를 재사용했다. Behavior Context는 4명 exact, 46명은 이미 pre-run 근거로 재구성된 텍스트다. 이번에 재생성하거나 프로필을 교체하지 않았지만, 원본 prep 자체가 사후 프로필·설정 snapshot을 사용했다. Brief fingerprint와 Behavior 근거 시점을 확인한 것만으로 전체 입력의 과거 시점 정합성을 보증할 수 없다.
- 과거 카드의 JD를 모든 arm에서 동일하게 고정했다. 12개 카드는 9,000자 길이로 보존돼 원문 잘림 가능성이 있다. 현재 JD로 이를 채우지 않았다. 카드의 저장된 updatedAt은 265건 모두 run 이전이지만 이것만으로 전체 원본 요청과의 동일성을 보증하지 않는다.
- 현재 예상 연봉은 사후 보강 정보다. 공백 제거 후 과거 카드와 현재 JD 텍스트가 같은 137건 중, 실제 예측 급여가 있는 **111건·31명**에만 추가했다(긍정 57·부정 54). 나머지 154건은 추정치를 넣지 않았다. 당시 이 값이 존재했거나 정확했음을 보장하지 않는다.
- 부정 사유의 구조화 선택값에는 직무 불일치 51건, ‘회사 혹은 조건이 기준을 충족하지 못해요.’ 31건, 근무 조건 26건 등이 있다. 복수 선택이 가능하며 회사/조건 사유를 회사 이름값만의 문제로 해석하지 않는다. 별도 내부 계정 분류는 하지 않았다.

사전 고정한 다섯 arm은 v6/no salary, v6/기존 연봉 표기, v8/no salary, v7/기존 연봉 표기, v8/강화한 연봉 표기다. 사용자 context·역할·순서·배치는 같은 조건이며 arm 순서만 순환한다. 이전 v7 rubric을 따로 동결해 이번 불확실성 수정의 차이를 비교했다. 결과를 보고 prompt·gold를 조정하거나 재호출하지 않았다.
