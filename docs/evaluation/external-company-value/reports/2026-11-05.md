# 회사 이동 가치·예상 연봉 Decisions 비교

2026-11-05. 제품 변경은 로컬 구현이며 미배포다. 이번 표본에서는 예상 연봉 추가가 사용자 피드백과의 순위 일치도를 낮췄다. 질문만 변경한 결과는 기준 재실행과 거의 같았다. 회사 수준 판단이나 실제 추천 성과가 개선됐다고 결론 내릴 수 없다.

## 구현

- 저장된 예상 기본급을 공개 연봉과 분리된 `estimatedBaseSalary` 텍스트로 Decisions 입력에 전달한다. 통화·기간·범위와 비공개 추정/성과급·주식 제외 의미를 보존하며 공개 급여 projection은 그대로 유지한다.
- candidateInterest·mutualFit과 공통 지침은 현재 경력·현실적 대안 대비 회사의 이름값, 보상, 동료 환경, 이후 경력 가치와 사용자가 선택한 tradeoff를 평가한다. employer/role/constraint/evidence의 기존 출력 구조는 유지한다.
- `opportunity_search` handbook은 같은 관점으로 최종 선택 목적을 설명한다. 평가 당시 예상 연봉을 검색 결과의 모델용 텍스트에도 제공한다.
- rubric은 `external-fit-questions-v7-company-value`, handbook은 `2026-11-05-v10`이다. 새 Career의 입력/evaluator fingerprint가 새 평가를 구분한다. 기존 v2 캐시도 이전 rubric을 현재 평가로 재사용하지 않는다. 과거 추천·점수는 수정하지 않는다.
- 정렬 가중치는 기존 요청의 30/50/10/10을 유지한다. 아래 비교에서 다른 가중치를 탐색했지만 최적값으로 선택하지 않았다.

## 설계와 실행

운영 DB를 읽기 전용으로 캡처했다. 당시 입력 snapshot과 정확한 evaluation ID/owner/role로 연결되고 평가 후 명시적 피드백이 있는 70건: 긍정 62, 부정 8, 사용자 19명이다. test-only 역할은 제외했다. 부정 피드백은 3명에게서 나왔고, 긍정·부정을 모두 남긴 사용자는 2명이다. 이 표본을 대표적인 생산 트래픽이라고 보지 않는다. 별도 내부 계정 분류는 하지 않았다.

70건 모두 현재 JD와 저장 당시 JD가 일치했다. 51건에 저장된 예상 연봉이 있었다. 연봉 추정에는 과거 생성 시점이 없으므로 사후 정보 보강 실험이며, 당시 이용 가능했음을 보장하지 않는다. 후보자 정보는 현재 프로필로 갱신하지 않고 당시 snapshot을 유지했다. 피드백·거절 이유는 모델 입력에서 제외했다.

4개 실험군의 정확한 입력/질문과 gold를 호출 전에 동결했다. 동일 context의 역할을 최대 10개씩 묶었고 모든 실험군에서 배치 구성을 같게 유지했다. 배치별 실험군 실행 순서를 순환했다. 원래 운영 배치와는 구성이 다를 수 있다.

## 정량 결과

AUC는 긍정 공고 점수가 부정 공고보다 높은 비율이며 동점은 0.5다. 노출된 뒤 피드백이 있는 공고끼리의 구분력이고, 추천 성공률·지원율·채용률이 아니다. `candidateInterest`를 실제 like 확률로 가정하지 않았다.

| 실험군 | candidateInterest AUC | 30/50/10/10 AUC | 같은 사용자 내 AUC 평균 |
| --- | ---: | ---: | ---: |
| 기존 저장 점수 — 참고 | 0.7198 | 0.7722 | 0.5000 |
| 기존 방식 재실행 | 0.7450 | 0.7379 | 0.4167 |
| 예상 연봉만 추가 | 0.6351 | 0.6371 | 0.0833 |

같은 사용자 내 비교는 2명뿐이므로 일반화할 수 없다. 전체 사용자 단위 2,000회 paired bootstrap 중 양쪽 label이 있는 1,922회로 계산한 정렬 AUC 차이의 95% 구간은 다음과 같다.

모든 구간이 0을 포함한다. point estimate의 악화는 관측됐지만 일반적인 효과 방향을 확정할 표본은 아니다. 과거 저장 점수와 동일 방식 재실행도 차이가 있으므로, 새 방식을 과거 저장 점수와만 비교해서 prompt 효과라고 해석하지 않는다.

## 사례 확인과 해석

익명 case031은 긍정 피드백이 있지만 candidateInterest가 baseline 63 → combined 8로 내려갔다. 질문만 바꾼 값은 70이었다. 낮은 예상 연봉이 제공된 상황에서 큰 하락이 관측된다. 익명 case023은 직무 불일치로 거절됐지만 baseline 36 → combined 73으로 올라갔고, 높은 예상 연봉이 제공됐다. 숫자의 변화와 입력은 관측 사실이며 모델의 내부 이유를 직접 읽은 것은 아니다.

예상 연봉이 틀렸다고 확정할 실제 제안 보상은 없다. 희망 기본급 대비 추정치가 낮은 긍정 공고를 벌점화하거나, 회사/보상이 매력적인 부정 공고를 올릴 가능성이 보인다. 좋아요에는 저장·기존 지원 관리도 포함돼 있어 실제 이직 수락과 동일한 정답이 아니다.

8개 부정 피드백에는 직무·경력·역할 규모·근무 조건·경쟁사 관련 이유가 있었다. 회사의 이름값/수준이 낮아서 거절한 표본은 이 세트에서 직접 확인되지 않았다. 따라서 사용자가 제기한 회사 수준 문제를 이 평가가 직접 검증했다고 볼 수 없다. Handbook에 의한 최종 선택 변화 역시 이번 Decisions 실험 범위 밖이다.

현재 추정 연봉을 그대로 추가하는 안을 검증된 운영 개선으로 권고하지 않는다. 회사 수준 때문에 거절한 사례와 관측 보상 근거가 있는 별도 고정 표본으로 재검증하는 것이 다음 단계다. 이번 입력·질문은 결과를 본 뒤 조정하거나 재호출하지 않았고, 로컬 구현은 미배포 실험 상태로 남겼다.
