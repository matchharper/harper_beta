# Onboarding continuation

Synthetic first-action smoke probes for the direct web continuation. Frozen v1 cases below distinguish an entry posting without introduction consent, an explicit request to pursue that posting, and general opportunity discovery. Reviewer expectations: use current facts and appropriate general tools; do not infer sharing consent from entry alone or claim unexecuted work. Inspect full input/output manually; there is no semantic automated judge.

Run `NODE_PATH=./node_modules/next/dist/compiled NODE_OPTIONS=--conditions=react-server pnpm exec tsx --tsconfig scripts/tsconfig.json scripts/evalCareerOnboardingContinuation.ts` from harper_beta. Uses the configured default Career text model, production normal-chat prompt builder, onboarding continuation instruction, and eligible tool schemas. By default stops after the first tool call and returns a synthetic nonexecution receipt. No tool effects or DB calls are permitted; network is restricted to model providers. This probes initial decisions, not a full capability selector, search, delivery or UI E2E. Exact provider inputs, output and source hashes are saved owner-only in ignored runs/. A successful smoke probe alone is not a deployment gate.


## Complete-turn probe
`--complete` runs the same frozen cases through the model/tool loop to completion, using frozen `tool-evidence-v2.json` for synthetic tool observations. The catalog has 13 roles at 12 companies, including two Cedar roles. Exact inputs/outputs and fixture hashes remain in runs/. Review the original final response, authorization boundaries, and recommendations manually. The chat transport now saves final text itself through the existing idempotent contact executor; contact_user is not offered to the conversation model. Unknown tools fail visibly. No company/application/queue/DB effects occur; Saved/delivered receipts come only from the isolated fixture adapter. This exercises the production prompt/serializer/tool loop with the full tool catalog, not the production preload selector or real search ranking. The four-minute deadline is a test cost limit.

The initial complete probe used v1 evidence with explicitly synthetic result labels and missing read/search adapters; its errors are preserved in the review. v2 freezes ordinary-shaped observations and URLs in reserved .example domains, with missing profile/context adapters supplied. No real jobs or users are represented.
