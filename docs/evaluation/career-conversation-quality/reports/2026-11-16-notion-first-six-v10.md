# Harper 첫 대화 여섯 건 · 실제 모델 비교

2026년 11월 16일. 같은 여섯 사람이 가입한 뒤 보낸 24개 메시지를 변경 전후 모델에 각각 전달했다. 오늘의집 사용자가 Gmail을 연결하면 별도 서버 이벤트로 Harper를 한 번 더 호출했다. 사용자 발화가 없는 가입 직후 여섯 턴까지 합쳐 한쪽당 31턴이다. 모델은 매번 자신이 실제로 했던 답변과 그 시점까지 저장한 자료만 받았다. [원본 대화](../ideal-dialogues-v9.md) · [고정 입력](../cases-v10.json)

11월 17일 본문에 연결된 62개 턴에서 원본 모델 응답 ID와 비용을 다시 대조했다. 변경 전 세 대화를 재실행한 기록이 이전 비용 합계에서 빠져 있었다. Career 모델 호출은 107회에서 127회, 해당 모델의 추정 비용은 $1.55735에서 $1.77484로 늘었다. 매 턴 기능을 고르는 Decisions 호출 31건씩을 더하면 31턴의 모델 비용은 **$1.570 → $1.788**이다. 두 조건 모두 같은 공개 자료를 재생했으므로 외부 검색료는 여기에 포함하지 않았다. 별도로 실제 웹에서 Bjak 공고를 찾아 카드로 보여 준 한 턴의 Exa 기록은 $0.088이었다.

검색 횟수에는 웹 검색을 요청한 도구 호출을 셌다. 여러 URL을 한 번의 호출로 열면 각 URL을 한 건씩 셌다. 재열람은 같은 사람의 대화에서 앞서 열었던 URL을 한 번 더 요청한 횟수다. 페이지를 나눠 읽거나 조건을 확인하는 데 필요한 재열람도 포함한다. 여섯 대화는 병렬로 실행했다. 같은 입력으로 각 조건을 한 번씩 실행했으므로 이 수치만으로 평균 비용이나 재현 확률을 추정할 수 없다.

두 조건 모두 실제 Career 모델 `gpt-6.1-terra`의 high 설정과 운영 도구 스키마를 사용했다. 이력서, 프로필 링크, 가입한 공고, Gmail 연결 여부는 그 시점까지 알려진 값만 넣었다. 공유 가능한 실제 자료는 14개 페이지와 운영 DB에서 조회한 Toronto·NARWHAL의 공개 채용 정보다. 사람·경력·받은 편지는 노션이 가정한 데이터를 사용했다.

도구는 실제 모델이 고른 인자대로 격리된 문서·이력·제공된 메일과 공개 자료를 조회하고 저장한다. 따라서 사용자가 본 답변과 확인 양식은 평가할 수 있다. 운영 화면의 클릭, 실메일 도착, 기업의 수신 또는 채용 성과에는 별도 증거가 필요하다. Coupang의 신고 급여 페이지는 제품 리더 재조회에서도 본문을 읽지 못했다.

가입 직후와 Gmail 연결 이벤트에서는 모델이 도구 사이에 쓴 문장이 사용자에게 전송되지 않는다. 아래에는 그 이벤트의 최종 답변만 실었다. 최초 v10 실행은 해당 문장을 다음 턴의 이력에도 포함했다. 특히 Gmail 연결 뒤 대화는 수정한 이력으로 따로 실행했다. 일반 채팅에서는 도구 사이에 쓴 문장이 실제 채팅 메시지로 저장되고, 도구별 상태는 진행 로그로 따로 보인다.
