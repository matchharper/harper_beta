# 병행 폼·브라우저 표시 v4

범위는 실제 사용자 Chrome의 기존 Career 대화에서 독립적인 폼 2개, 브라우저 2개와 특정 브라우저 확대를 관측하는 것이다. v3 지원서 작성 완료 집계와 별도인 UI/응답 전달 검증이다.

기존 채널톡 지원 정보의 연락처와 링크를 각각 독립 폼으로 나누어 수정 요청하고, 실제 공고 본문과 지원 페이지를 별도 브라우저로 열어 달라고 요청한다. tool 이름이나 마커를 사용자 요청에 넣지 않는다. 두 폼의 응답을 연달아 저장할 수 있는지, 각 원문·revision·값이 보존되고 기존 대화가 이어지는지 확인한다. 제출·메일 발송 CTA를 누르지 않는다.

통과 기준: 여러 폼의 독립 입력·저장, 중복 클릭의 동일 응답 재사용, 활성 브라우저의 composer 우측 상단 겹침, 특정 마커에 따른 자동 확대와 재열기, 확대 중 동일 iframe 유지, 세션 종료 후 팝업 제거. 로그인 제어권 전환과 실제 지원 성공은 이 UI 검증의 성공 수에 포함하지 않는다.

실행은 기존 수동 Chrome 경로와 제품 API/worker만 사용한다. 모델 설정·요청 원문·tool/record ID·렌더링 스크린샷은 ignored runs/browser-dock-v16/에 보관한다. 기존 frozen input/gold와 실행 기록을 덮어쓰지 않는다.
