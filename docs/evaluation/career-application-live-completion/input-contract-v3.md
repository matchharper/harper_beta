# ChannelTalk 최종 확인 흐름 v3

2026-10-30 사용자의 추가 요청으로 같은 실제 ChannelTalk 공고에서 최소 5회 반복한다. 기존 18개 공고 검증과 별도 집계한다. 사용자 Chrome·기존 계정·실제 product UI만 사용한다. 새 내부 Role이나 합성 인물은 만들지 않는다.

첫 요청은 해당 공고에 지원 준비를 맡기며, 최종 제출 전 Harper에서 확인한다는 범위를 전달한다. 이후 독립 재작성·수정 반영·검토 폼 재표시·만료 후 재개 등 실제 후속 요청으로 5회 각각의 최종 폼과 외부 화면을 관측한다. 요청 원문·변형·모델·실패·재시도는 private 원장에 보존한다. tool 이름을 요청에 넣어 호출을 대신 지시하지 않는다.

기존 대화의 과거 보류 요청과 다른 현재 권한은 첫 요청에 명시한다: 일반 입력과 필수·선택 개인정보 동의는 Harper가 준비하고, 최종 제출만 확인 뒤 진행한다. 실제 제출 CTA를 실행자로 대신 누르지 않는다. 개인정보 선택 준비와 최종 외부 제출 승인을 구분한다.
