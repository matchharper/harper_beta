# 첫 요청 v2 — 과거 자료 복구 후

v1의 종료·권한 범위는 유지한다. 과거 E2E 합성 경력과 해당 파생 문서의 별도 복구가 확인된 뒤, 같은 대화에 남은 과거 답변을 현재 사실로 재사용하지 않도록 실제 사용자 요청에 아래 정정 한 문장을 추가한다. 원본 v1과 이전 attempt는 변경하지 않는다.

> 이전 테스트로 잘못 저장된 경력과 문서는 정리했으니 현재 저장된 이력서와 프로필을 다시 읽고 사용해줘.

그 뒤 공고별 실제 요청과 정확한 URL을 전달한다. 기본 준비 요청은 다음과 같으며 실제 전송 문구가 다르면 private 원장에 그대로 남긴다.

> {회사명} · {공고명}에 지원하고 싶어. 내 이력서를 골라 필요한 내용을 준비하고, 실제 지원 사이트에서 제출 직전까지 진행해줘. 최종 제출이나 메일 발송은 하지 마. 로그인이 필요하면 내가 로그인할 수 있게 브라우저를 열어 두고 알려줘.

정정 문장은 숨은 시스템 prompt나 실행 분기가 아닌 실제 사용자 입력이다. 이미 같은 대화에 정정을 전달했다면 뒤따르는 별도 공고 요청에 반복된 것으로 기록하지 않는다. 공고의 근무 조건·필수 질문을 사용자의 답변으로 가정하지 않으며, 질문·로그인·후속 지시와 재시도는 실제 원문으로 보존한다. 종료 기준은 변경하지 않는다.
