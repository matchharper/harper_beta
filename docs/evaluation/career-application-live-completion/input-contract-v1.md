# 첫 요청 v1

새 공고를 시작할 때 아래 요청의 회사·공고명·공고 참조만 바꾼다. 실제 role mention 또는 정확한 URL을 함께 전달한다. 사용자 권한이나 필수 질문의 답변을 추가로 가정하지 않는다.

> {회사명} · {공고명}에 지원하고 싶어. 내 이력서를 골라 필요한 내용을 준비하고, 실제 지원 사이트에서 제출 직전까지 진행해줘. 최종 제출이나 메일 발송은 하지 마. 로그인이 필요하면 내가 로그인할 수 있게 브라우저를 열어 두고 알려줘.

기존 case를 이어갈 때는 위 문장을 새로 보낸 것으로 기록하지 않는다. 질문에 대한 실제 사용자 답변, 사용자 로그인, 재시도, 정정은 해당 원문을 attempt에 남긴다. 없는 답변을 평가자가 만들어서 제공하지 않는다. 종료 유형 A–E는 평가자의 수동 판정 기준이며 위 요청에 시나리오별 절차를 덧붙이거나 모델 prompt에 주입하지 않는다.
