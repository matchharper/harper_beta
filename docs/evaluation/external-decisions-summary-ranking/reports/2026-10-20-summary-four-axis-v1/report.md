## 해석과 재현 범위

- 비용은 API usage에 공식 Decisions 단가($0.10/입력100만토큰, 캐시 읽기/쓰기·출력0)를 적용한 추정이며 청구서 실액이 아니다. API 토큰은 실제 영수증이다. 계정별 조정·regional/long-context premium은 적용 증거가 없으므로 추정에 포함하지 않았다. raw usage와 모델 식별자는 private 영수증에 보존했다.
