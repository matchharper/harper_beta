# Apply with Harper 비동기 준비 점검 — 2026-10-13

로컬 구현·검증 기록이며 배포 상태를 의미하지 않는다.

## 변경

- 처음에는 이력·프로필, 포지션·회사, 맞춤 제안의 세 단계만 진행한다.
- 첫 제안 발행 후 지원 양식 조사는 별도로 실행하고 기존 지원 activity에 결과와 대리 지원 가능 여부를 저장한다. 새 테이블은 없다.
- 입력이 조사보다 빠르면 답변을 먼저 저장하고 조사 완료를 기다린다. 조사 결과는 최신 revision에 합쳐 답변을 덮어쓰지 않는다. 중복 실행 방지, 종료된 세션 보호, 만료된 실행 복구를 포함한다.
- 이후 LLM은 관찰한 필수 항목 중 알려지지 않은 내용만 묻거나 초안을 제안한다. 로그인 필수·확인 불가이면 준비한 이력서와 직접 지원 URL을 제공한다.
- 요청 연결의 abort 신호를 서버가 시작한 준비 작업에 전달하지 않고 응답 이후에도 작업 수명을 유지한다. 실패 시 단계·오류명·원인·소요 시간을 기록한다.
- 완료/실패 시 진행 카드와 그래픽 영역을 유지하고 정지 모습으로 바꾼다. 연결이 끊긴 뒤에는 저장된 답변으로 계속할 수 있는 버튼을 표시한다.

## 최초 오류에 관해 확인된 범위

기존 로컬 Next 로그에서 시작 카드 표시와 준비 시작은 모두 true였고, 나중에 cancelled와 빈 reason이 반환되었다. 당시 코드에서 이 상태는 요청 abort와 연결되어 있었다. 어떤 브라우저/네트워크 사건이 최초 abort를 일으켰는지는 보존된 로그로 확정하지 못했다. LLM이 카드와 준비가 아예 시작되지 않았다고 설명한 것은 도구 결과와 불일치했다. 현재 시작 결과 지침은 시작 사실과 미완료 상태를 구분한다.
