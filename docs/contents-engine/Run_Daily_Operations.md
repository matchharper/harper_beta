# Run_Daily_Operations.md

버전: 1.1 · 적용일: 2026-09-17 · 상태: active (범위는 Connections 기준) · 관리: 아래 관리 역할

[AGENTS.md](AGENTS.md)를 먼저 읽는다. 이 문서는 해당 작업의 입력 파악부터 분석·실행·저장·결과 확인까지 소유한다. 외부 발송·게시·송금·플랫폼 API 연결은 문서만으로 생기지 않는다.

## 업무 계약

- **호출 상황:** ‘오늘 처리할 일 정리해’, ‘진행 중인 것 챙겨줘’, ‘내가 판단할 것만 모아줘’. 향후 예약 실행도 동일 문서와 명시된 범위를 사용한다.
- **입력·근거:** 활성 집행·협업·콘텐츠뿐 아니라 미분류 문의와 종료 후 남은 의무, 최신 회신·기한·미완료 action_items·지급 의무·수집 실패, 이미 실행 중인 작업과 권한.
- **소유하는 방법:** 실제 상태 갱신 → 놓칠 약속과 막힌 작업 확인 → 영향·기한·담당을 근거로 우선순위 정리 → 맡겨진 범위의 일은 해당 작업 문서로 수행 → 팀원의 판단이 필요한 항목만 근거와 선택지로 전달 → 남은 다음 행동 정리.
- **저장:** 원래 협업·콘텐츠·집행의 상태와 항목별 실제 후속 업무(action_items), 수행 활동. 통계 제출·지급 확인처럼 동시에 남은 일을 각각 보존하며 대표 다음 행동 하나로 나머지를 덮어쓰지 않는다. 별도 ‘오늘 할 일’ 테이블은 만들지 않는다.
- **완료:** 무엇이 처리됐고 무엇이 남았는지, 각 담당·기한·막힌 이유가 명확하다. 전체 표를 복사해서 보고하는 것으로 끝내지 않는다.
- **예외·경계:** 일간 작업은 여러 업무의 실행을 연결하지만 자체 협상·성과 해석 규칙을 복제하지 않는다. 단순 상태 확인 요청이 발송·지출 허용은 아니다. 예약 자동화를 만들 때에는 대상·시간·권한·의미 있는 변화 알림 기준을 실제로 설정한다. 지금 예약을 생성하는 것은 아니다.
- **관리:** 운영 담당이 누락 약속·불필요한 알림·팀원 개입 시간으로 개선한다.

## 현재 도구로 끝까지 수행하기

[Connections.md](Connections.md)의 Supabase plugin 및 `gtm_workspace` 호출 계약을 사용한다. 칼럼은 [data-model.md](data-model.md), 제품 사실은 [Business_Context.md](Business_Context.md), 계산은 [measurement.md](measurement.md)가 원본이다.

1. `today`를 읽고 미분류 협업·기한이 도래한 콘텐츠·비용·최근 collection_result를 필요한 만큼 list/get으로 보완한다. `list gtm_creators`에서 `data_status`가 missing_accounts/incomplete/stale인 현재 후보와 `outreach_status`가 awaiting_reply/replied인 대상을 함께 확인한다. 종료된 부모의 남은 업무도 포함한다.
2. 최신 회신/제출 근거와 미완료 의무를 확인하고 실제 영향·기한·담당으로 우선순위를 정한다. 해석은 Agent가 원문으로 수행한다.
3. 이미 맡겨진 범위는 해당 작업 문서로 수행한다. 독립 업무별 기존 ID와 문서 버전을 유지하고 새 원장을 만들지 않는다.
4. `patch_item action_items`로 처리한 항목만 done/cancelled로 반영한다. 다른 업무를 덮어쓰지 않는다. 실패에는 원인·다음 조치·담당·기한을 남긴다.
5. 처리 완료, 대기 중, 팀원의 판단이 필요한 사항을 짧게 보고한다. 현재 정기 Agent 실행/메일 수신 자동화는 미설정이다. 스케줄이 실제 만들어졌다는 근거 없이 매일 자동 실행된다고 보고하지 않는다.

## 중단·충돌·완료 확인

같은 쓰기를 재시도할 때 request_id와 본문을 유지한다. row_version 충돌은 최신 행을 읽고 실제 변경을 재판단한다. 애매한 외부 결과를 성공으로 기록하지 않는다. 외부 입력을 기다리면 기존 원장의 실제 할 일·담당·기한·재개 조건을 남긴다. 결과에는 사용한 문서 버전, 저장한 원장 ref/ID, 실제 완료 범위와 남은 사항을 포함한다.
