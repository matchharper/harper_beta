# Internal 회사 조사 스냅샷 갱신 기준

## 목적

`company_workspace.is_internal = true`인 회사의 `/career` 회사 상세 화면에 최신 한국어 소개를 제공한다. 글은 후보자가 회사를 빠르게 이해하고 관심을 가질 수 있게 쓰되, 확인되지 않은 사실을 홍보 문구처럼 단정하지 않는다.

## 정보 우선순위

1. Harper가 회사로부터 제공받은 후보자 공개 가능 정보와 `company_workspace.pitch`
2. 회사 홈페이지, 공식 블로그, 채용 페이지와 보도자료
3. 신뢰할 만한 언론, 투자사와 공개 데이터

내부 정보가 있으면 공개 자료보다 먼저 회사의 실제 채용 맥락과 지역 팀 기회를 설명하는 데 활용한다. 다만 후보자에게 공개하면 안 되는 채용 기준, 연락처, 계약 조건, 개인 정보와 영업상 비밀은 넣지 않는다. 내부 정보가 없으면 공개적으로 확인되는 사실만으로 작성한다.

## 작성 방식

- 첫 문단은 회사의 가장 강한 성장, 제품, 고객 또는 팀 기회를 담은 3문장으로 시작한다.
- 이후 회사가 주목받는 이유, 제품과 차별점, 창업자·팀, 한국 또는 글로벌 채용 기회를 짧은 Markdown 섹션으로 설명한다.
- 후보자의 관심을 떨어뜨리는 별도 `지원 전에 알아둘 점` 섹션은 만들지 않는다. 필요한 근무 방식이나 역할 특성은 채용 기회 문맥에서 사실대로 설명한다.
- 숫자와 현재 상태에는 기준 시점과 출처를 남긴다. 회사가 발표한 성과는 회사 발표임을 알 수 있게 쓴다.
- 마지막에 실제로 참고한 공개 URL을 출처로 적고, 공개되지 않은 정보는 `Harper 내부 제공 정보`로 구분한다.

## 저장과 확인

- 언어는 `ko`, 상태는 `completed`로 새 `company_snapshot` row에 저장해 기존 이력을 보존한다.
- `metadata.investigation_date`와 실행을 식별할 revision을 기록한다.
- 저장 후 각 회사에서 최신 한국어 완료본이 선택되는지, Markdown이 비어 있지 않은지, 금지된 내부 정보가 포함되지 않았는지 확인한다.
- `company_db_id`가 없거나 회사를 정확히 식별할 수 없으면 추정해서 저장하지 않고 보류한다.
