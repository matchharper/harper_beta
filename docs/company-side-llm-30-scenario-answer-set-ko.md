# Company-side LLM 회사 발화–Harper 이상 응답 30선

이 문서는 `/org`와 Slack에서 동작하는 company-side LLM의 응답 품질을 검토하기
위한 예시 모음이다. 아래 응답은 그대로 복사하는 고정 문구가 아니라, 사용자의 질문에
충분히 답하면서도 Harper가 다음 판단과 실행까지 적극적으로 돕는 수준을 보여주는 기준이다.
실제 응답은 workspace 데이터와 대화 맥락에 맞게 자연스럽게 달라져야 한다.

`<후보자>`, `<포지션>`, `<회사>`, `<근거>` 등은 실제 조회 결과로 치환한다.

아래 실제 출력은 2026-08-06에 `gpt-5.6-luna`와 완결된 synthetic workspace fixture
(`샘플테크`, FDE·Product Designer 역할, 서로 다른 프로필의 후보자 3명)를 사용해
production과 같은 company-side LLM prompt·tool loop로 각 시나리오를 실행한 결과다.
쓰기·연락·연결은 실제 실행 경로를 검증하되 외부 사용자에게 영향을 주지 않는 mock
terminal write로 처리했다. 최종 기록은 수정 후 실제로 통과한 대표 실행 결과를 사용한다.

## 검증 시 주의사항

이 문서의 문장을 그대로 재현하는지 검사하지 않는다. 각 시나리오를 다른 이름, 포지션,
언어와 표현으로 바꿔 실행하고 다음을 의미 단위로 평가한다.

1. 회사가 실제로 물은 질문에 충분히 답했는가.
2. 필요한 데이터를 조회하고 중요한 근거와 한계를 함께 설명했는가.
3. 단순히 답만 끝내지 않고 도움이 되는 다음 판단이나 행동을 제시했는가.
4. 쓰기, 연락, 연결의 실행 상태를 과장하지 않았는가.
5. 관련 없는 고정 답변이나 다른 시나리오의 답변으로 치환되지 않았는가.

이번 실행에서는 30개 시나리오가 모두 의미 판정과 공통 안전 검사를 통과했다. 다만 LLM
응답은 비결정적이므로 이 결과를 영구 보장으로 보지 않으며, prompt·tool·model 변경 시 같은
완결 fixture로 30개를 다시 실행해 회귀 여부를 확인한다.
